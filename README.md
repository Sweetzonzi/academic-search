# academic-search：面向本课题组的 LLM 文献检索与阅读辅助技能

一套**本地优先**的文献工作流，装进 agent 就能用：按研究领域检索论文（OpenAlex、arXiv、Crossref）→ 先本地去重再联网 → 结果进"候选池" → 按策略入库 → **全文文本化成 LLM 读得懂的 Markdown（含图件与锚点）** → 中文摘要与翻译缓存在本地 → 支持查阅、精读问答与总结；未来扩展到引用图谱与研究脉络。

面向**本课题组**：各人研究方向不同，画像各自独立；装了 Zotero 的人用它管条目与附件，没装的人走文件库后端，工具行为一致；结果通过导出文件交接，不建共享库。

由三部分组成：**一个确定性 CLI**（干重活）+ **一个薄 SKILL.md**（告诉 agent 何时调用）+ **一个 sidecar SQLite**（存语料与派生数据），「我的库」由 `LibraryBackend` 抽象，Zotero 只是默认实现。

## 五个必须先知道的事实

1. **Zotero 是"我的库"的权威，sidecar 是"领域语料 + 派生数据"的权威**，两者单向流动（promote），没有字段两处可改。「我的库」由 `LibraryBackend` 抽象，Zotero 只是默认实现（同学不装 Zotero 也能用）。
2. **全库没有任何随机生成的标识符**：一条记录的 id 由 `(来源, 来源内 id)` **确定性派生**（`record_uid`），一篇作品的键**直接就是组内最早那条记录的 `record_uid`**（`work_key`）。两台机器看同一批来源会得到同样的 id 与同样的 `blobs/` 路径，删库重建后也完全一致。第三方 ID（OpenAlex `W…` / DOI / arXiv）只作别名——因为实测被合并/删除的 OpenAlex Work ID **返回 404 且没有跳转**，2025 年后连"旧 ID → 新 ID"的映射都不再提供；标题哈希跨来源碰撞 16%（最大 7 篇同名）。见 [03 D3](docs/03-设计说明书.md)、[05 §8](docs/05-实验记录-文本化.md)。
3. **同一篇论文的多个来源统统存下来，不做破坏性合并**：每条来源记录各占一行（`record`），由**可重分组的 `work` 视图**把它们归为一篇；合并只是**重定向**（`merged_into`），永不改名、永不删记录。派生数据（翻译/摘要/文本化）按**源文本内容哈希**共享，字节按 `sha256` 内容寻址。写入因此无需跨源仲裁，也永远不会因为一次误合而静默毁数据。见 [03 D11](docs/03-设计说明书.md)。
4. **默认只建"仅元信息条目"**（不带 PDF）：检索、去重、引用、中文摘要都能做；PDF 在首次精读时按需挂到同一条目上。
5. **全文文本化走"原生文本优先"，且以 arXiv LaTeX 源码为主、HTML 为辅**：源码 / HTML → pandoc → Markdown（图件随文落盘、锚点注入），PDF→MD 仅作回退。Markdown 给 LLM 读，HTML 给 Zotero 索引与标注。**注意 pandoc 的原始输出不能直接用**——必须配一层归一化；HTML 只作回退与补强（它的数学里会漏出无法渲染的自定义宏）。实测依据见 [05](docs/05-实验记录-文本化.md)。

## 目录约定（规划）

```
academic-search/
├─ README.md                  # 本文件：导航与状态
├─ AGENTS.md                  # 文档维护约束（自包含性）
├─ docs/                      # 需求 / 调研 / 设计 / 计划 / 实验记录
├─ tools/                     # 维护工具（doc_check / selfcheck / test_doc_check）
├─ skills/academic-search/    # 交付物：SKILL.md + references/ + scripts/
├─ src/                       # CLI 实现（核心链路仅用标准库）
├─ store/                     # 内容寻址的字节存储（<sha 前2位>/<sha256>，不进版本库）
├─ blobs/<work_key>/          # 给人看的产物投影（可重建）
├─ data/                      # sidecar.db、reports/、spike 产物（不进版本库）
└─ tests/
```
