## 1. 命令与输出

| 命令 | 作用 | 关键约束 |
|---|---|---|
| `search` | **刷新（可选）→ 查库 → 返回**（[ADR-0043](决策/ADR-0043.md)）。两种入口并列：用画像里的**具名查询**，或当场给**临时检索式**（[ADR-0041](决策/ADR-0041.md)）。返回分级候选 | `--query <具名查询>` 或 `--all-of`／`--any-of`／`--venue`／`--author`／`--since-years`（两者互斥，字段语义与画像一致）；`--topic <标签>`（缺省 `ad-hoc`）；`--limit`、`--source`、`--refresh auto\|true\|false`（默认 `auto`＝按检索式新鲜度自行判断并**标注是否跳过**；`true`＝强制刷新；`false`＝**绝不联网**。**三值都必须显式给出，不接受裸写**）、`--max-age <时长>`（单次覆盖阈值）（[ADR-0043](决策/ADR-0043.md)）、`--in meta\|body\|both`（默认 `meta`；`body` 扫 `works/`，[ADR-0036](决策/ADR-0036.md)） |
| `lookup` | 按 DOI/arXiv ID/标题取条目或候选 | 走 §4.3.4 三段顺序；`--refresh`（同上）——**命中即返回**（标识确定，「外面有没有新的」对它不成立），是省钱的正确入口（[ADR-0043](决策/ADR-0043.md)） |
| `dedupe` | 对给定集合做分组判定（离线优先，只读 sqlite） | 返回"归入哪个 work / 新建 work"及判据 |
| `stage` | 候选落 sidecar（带理由与原始响应） | 幂等，唯一索引 |
| `promote` | 候选入 Zotero（专用 collection + provenance tag） | **M5**；`--dry-run` 先行；可按 `run_id` 回滚 |
| `digest list` / `digest put` | 翻译与摘要的**两段式**通道：`list` 输出待处理条目与源文本，`put` 收下 agent 产出的文本写回缓存 | **CLI 不调 LLM**（[ADR-0037](决策/ADR-0037.md)）；按 `content_hash` + `model_id` + `prompt_version` 去重；`--limit` 限流；`--no-note`（**M5**）控制是否写回 Zotero |
| `read` | 取条目全文（优先 `paper.md`）或指定页/段落 | 输出必须带 `work_key` + 锚点（页码或章节号）；M5 起附 itemKey |
| `textify` | 取原生文本源并转 Markdown（含图件落盘、锚点注入）——**「要这篇」的入口** | `--source auto\|latex\|html\|pdf`；转换器版本进缓存键；幂等，命中缓存零成本（[ADR-0035](决策/ADR-0035.md)） |
| `export` / `bundle` | 导出给他人或其他工具的产物；也是「把这批文件放到我要的位置」的通道 | `--work <work_key>`、`--out <路径>`、`--format md\|zip\|bibtex\|ris\|csljson`；`md/zip` 包内自带 `figures/`；**从 `works/` 复制出去，不改动投影** |
| `sync` | 增量采集（无头，供任意调度器调用） | `--query <具名查询>`；水位 + `run_id` + `run.json`（报告分「新发表 / 新发现」两栏）；**不含调度语义**（[ADR-0038](决策/ADR-0038.md)） |
| `graph` | 引用边抓取、脉络查询、导出 Mermaid/Graphviz | 节点上限与分页取样 |
| `verify` | 抽样重算 `bytes/` 里文件的 `sha256`，与文件名比对 | 只读；发现不匹配即报 `bytes/` 被外部改写（[ADR-0034](决策/ADR-0034.md)） |
| `profile` | 画像的**只读**通道：`show` 回显、`check` 解析校验并查重、`scaffold` 吐模板 | **CLI 不写配置**；新建与修改由 agent 直接写 `config/profile.toml`（[ADR-0039](决策/ADR-0039.md)、[ADR-0040](决策/ADR-0040.md)） |

**初版不执行的命令**：`promote` 与 `--no-note` 写回顺延到 M5（[ADR-0032](决策/ADR-0032.md)）。

**输出契约**：单一信封 `{ok, command, schema: 1, data | error{message, code}}`，其中 `data` 对检索类命令**必带 `network`（本次是否发过请求）与 `cost`（花费及口径）**；结果条目带 `first_seen`；`run` 账本记 `spec_hash` 与 `refreshed`（[ADR-0043](决策/ADR-0043.md)），成功失败都写 stdout，日志写 stderr，`SCHEMA_VERSION` **只增不删**；退出码 0 成功 / 1 失败（可细分）。

**CLI 不调 LLM**：翻译与摘要走 `digest list` / `digest put` 两段式，模型由 agent 侧提供（[ADR-0037](决策/ADR-0037.md)）。

**依赖策略**：核心链路仅用标准库（`urllib.request`、`json`、`sqlite3`、`xml.etree`）；重活（向量、PDF 版面、Zotero 客户端库）放独立虚拟环境按需启用。
