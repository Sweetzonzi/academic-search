## 1. 命令与输出

| 命令 | 作用 | 关键约束 |
|---|---|---|
| `search` | **当场给的检索式 → 刷新（可选）→ 查库 → 返回结果列表**（[ADR-0043](决策/ADR-0043.md)）。**只接受临时检索式**；画像里的具名查询由 `sync` 执行（[ADR-0049](决策/ADR-0049.md)） | `--all-of`／`--any-of`／`--venue`／`--author`／`--since-years`（当场给检索式，字段语义与画像一致）；`--limit`、`--source`、`--refresh auto\|true\|false`（默认 `auto`＝按检索式新鲜度自行判断并**标注是否跳过**；`true`＝强制刷新；`false`＝**绝不联网**。**三值都必须显式给出，不接受裸写**）、`--max-age <时长>`（单次覆盖阈值）（[ADR-0043](决策/ADR-0043.md)）、`--in meta\|body\|both`（默认 `meta`；`meta` 只查标题摘要、`body` **只**扫 `works/` 且不联网、`both` 取并集，[ADR-0036](决策/ADR-0036.md)）、`--abstract`（布尔开关，默认关；打开时每条摘要截断到 `search.toml` 的 `abstract.chars`，默认 800，[ADR-0058](决策/ADR-0058.md)／[ADR-0059](决策/ADR-0059.md)）。**初版的质量过滤只有硬排除**（撤稿、`paratext`/`erratum`、载体黑名单，无条件排除）；`--min-grade` 与 A/B/C 分级顺延（[ADR-0051](决策/ADR-0051.md)）。`--limit` 默认 20（计合并去重后的 work 数），**只截断展示**——一次远端取数固定取一页 100 条；`--sort citations|date`（默认按 `published_at` 降序）是**取数条件**，与 `--source`、`--min-citations N`、`--min-fwci X` 一同进 `spec_hash`；后两个阈值两端同判、空值不通过，与 `--venue` 白名单一样会**跳过 arXiv 腿**（该腿如实记 0、不报错）（[ADR-0060](决策/ADR-0060.md)、[ADR-0061](决策/ADR-0061.md)、[ADR-0062](决策/ADR-0062.md)）。`--venue` 与会名一样要求**登记表里解析得到**，解析不到即 `invalid_args`（可直写 `S…`） |
| `lookup` | 按 DOI/arXiv ID/标题取条目或候选 | 走 §4.3.4 三段顺序（初版第 ① 层为空，实际是候选池 → 联网两层）；`--refresh` 三值与 `search` 同义（[ADR-0065](决策/ADR-0065.md)）：`true` = **先刷再查本地**——本地已按标识命中也会刷一次，用来更新引用数与安全信号（单实体 GET 免费）；`auto` = 本地未命中才联网；`false` = 绝不联网。`--title` 在 `true` 下降级为只查本地并在 `degraded` 里标注——标题不是标识，用不了单实体 GET |
| `promote` | 候选入 Zotero（专用 collection + provenance tag） | **M5**；`--dry-run` 先行；可按 `run_id` 回滚 |
| `digest list` / `digest put` | 翻译与摘要的**两段式**通道：`list` 输出待处理条目与源文本，`put` 收下 agent 产出的文本写回缓存（文本落 `bytes/`，DB 只留缓存键与指针，[ADR-0045](决策/ADR-0045.md)） | `list` 输出 JSON 信封、`put` 从 stdin 收 JSON 数组（可批量，`--file` 亦可）；**CLI 不调 LLM**（[ADR-0037](决策/ADR-0037.md)）；按 `content_hash` + `kind` + `lang` + `model_id` + `prompt_version` + `terms_version` 去重；`--limit` 限流；`--no-note`（**M5**）控制是否写回 Zotero。载荷与 `kind` 枚举见 [IFACE-PAYLOAD](接口/输出载荷.md)（[ADR-0054](决策/ADR-0054.md)） |
| `download` | 取**原始字节**（arXiv LaTeX 源码 / arXiv HTML / PDF）落 `bytes/` 并投影到 `works/<proj>/`、登记 `artifact`——**只下载不转换** | `--source auto\|latex\|html\|pdf\|all`（默认 `auto` = LaTeX 优先、失败回退 HTML；`pdf` 只在显式给出时下载且**不解析**，PDF→MD 仍顺延；`all` = 三者都取）；`--refresh auto\|true\|false`（`auto` = 该 kind 没有产物或两侧版本不等才取、相等即零请求复用；`true` = 无视版本、带 HTTP 验证器条件 GET；`false` = 绝不联网）；版本判据见 [ADR-0067](决策/ADR-0067.md)，来源矩阵见 [REQ R3](01-需求说明.md) |
| `read` | **定位器 + 懒物化**：返回 `bytes/` 里的 `paper.md` 路径、图件映射与锚点行号索引（投影存在时另附 `works/` 路径）；全文由 agent 用自己的文件工具读 | 只接受 `--work <work_key>` 与 `--refresh auto\|true\|false`（默认 `auto`：有 `paper_md` 就用；`works/` 被删则本地重投影、不联网；缺正文才取件并转换。`false` 绝不联网，取不到报 `projection_missing`；`true` 先按 `download` 的 `true` 更新再转换）；载荷带 `doc.source_version` / `doc.remote_version` / `doc.stale`，见 [IFACE-PAYLOAD](接口/输出载荷.md)（[ADR-0067](决策/ADR-0067.md)） |
| `export` / `bundle` | 导出给他人或其他工具的产物；也是「把这批文件放到我要的位置」的通道。**初版不实现**：契约（含 `--format` 取值）保留，实现与验收顺延；`bundle` 是它的别名（[ADR-0051](决策/ADR-0051.md)） | `--work <work_key>`、`--out <路径>`、`--format md\|zip\|bibtex\|ris\|csljson`；`md/zip` 包内自带 `figures/`；**从 `works/` 复制出去，不改动投影** |
| `sync` | **画像里的具名查询 → 联网采集 → 落候选池 → 产出报告**。**初版唯一执行具名查询的入口**，供任意调度器无头调用 | `--query <具名查询>`（可重复；缺省 = 画像里全部启用的查询）、`--refresh auto|true|false`（默认 `auto`，按每条查询各自的 `spec_hash` 各记各的时间，[ADR-0066](决策/ADR-0066.md) 决策 7）；产物是 `data/runs/<run_id>/run.json` + `report.md`，并刷新 `data/latest-report.md`（报告分「新发表 / 新发现」两栏，[ADR-0028](决策/ADR-0028.md)、[ADR-0055](决策/ADR-0055.md)），stdout 只给 run 摘要（形状见 [IFACE-PAYLOAD §3](接口/输出载荷.md)：`data.runs[]` 逐 run 自包含，各是那份 `run.json` 的真子集）、**不返回结果清单**；每次跑写一行 `run` 账本（`spec_hash`、`query_name`、`window_from` / `window_to`、`refreshed`、`cost`、`counts`）；**不含调度语义**（[ADR-0038](决策/ADR-0038.md)） |
| `graph` | **M4（初版之外）**：引用边抓取、脉络查询、导出 Mermaid/Graphviz | 节点上限与分页取样；见 [ADR-0046](决策/ADR-0046.md) |
| `verify` | 抽样重算 `bytes/` 里文件的 `sha256`，与文件名比对 | `--sample N`（默认 20，`0` = 全量）；只读、不自动修复；发现不匹配即退出码 1 并列出文件（[ADR-0034](决策/ADR-0034.md)、[ADR-0055](决策/ADR-0055.md)） |
| `profile` | 画像的**只读**通道：`show` 回显、`check` 解析校验并查重、`scaffold` 吐模板 | **CLI 不写配置**；新建与修改由 agent 直接写 `config/profile.toml`（[ADR-0039](决策/ADR-0039.md)、[ADR-0040](决策/ADR-0040.md)）；字段集与缺省值见[配置目录](使用/配置.md) |

**检索式的两个来源各有一个入口**：当场给的检索式走 `search`，产出**结果列表**；画像里的具名查询走 `sync`，产出**报告文件**。两者共用同一条流水线、同一本 run 账本（[ADR-0049](决策/ADR-0049.md)、[ADR-0043](决策/ADR-0043.md)）。

**不给检索式 = 列本地库全部**：`search` 的 `--all-of` / `--any-of` 都为空时跳过 FTS 过滤，返回本地所有 `live` work（条数仍受 `--limit` 限制）。这是 [R12](01-需求说明.md) 列清单的入口，只读本地、必须配 `--refresh false`；载荷粒度与分页见 [IFACE-PAYLOAD §2](接口/输出载荷.md) 与 [ADR-0057](决策/ADR-0057.md)。

**初版不执行的命令**：`graph`（M4，[ADR-0046](决策/ADR-0046.md)）、`promote` 与 `--no-note` 写回（M5，[ADR-0032](决策/ADR-0032.md)）、`export` / `bundle`（初版不实现、契约保留，[ADR-0051](决策/ADR-0051.md)）。

**输出契约**：单一信封 `{ok, command, schema: 1, data | error{message, code}}`——**`data` 里装什么、错误码有哪些、枚举取值是什么，见 [IFACE-PAYLOAD](接口/输出载荷.md)**；其中 `data` 对检索类命令**必带 `network`（本次是否发过请求）与 `cost`（花费及口径）**；余额不足触发降级时 `network` 为否、并在输出里标注降级原因（[ADR-0051](决策/ADR-0051.md)）；结果条目带 `first_seen`；`run` 账本记 `spec_hash` 与 `refreshed`（[ADR-0043](决策/ADR-0043.md)），成功失败都写 stdout，日志写 stderr，`SCHEMA_VERSION` **只增不删**；退出码 0 成功 / 1 失败（信封内可细分；**参数解析失败不经信封**，退出码 2，见 [IFACE-PAYLOAD §6](接口/输出载荷.md)）。

**CLI 不调 LLM**：翻译与摘要走 `digest list` / `digest put` 两段式，模型由 agent 侧提供（[ADR-0037](决策/ADR-0037.md)）。

**依赖策略**：核心链路仅用标准库（`urllib.request`、`json`、`sqlite3`、`xml.etree`）；重活（向量、PDF 版面、Zotero 客户端库）放独立虚拟环境按需启用；便携 pandoc 落 `vendor/`（[ADR-0055](决策/ADR-0055.md)）。
