## 2. 已关闭（实测或决策）

- 便携 pandoc 的体积、许可与更新方式 → [EX-2026-10-14-textify §1.2](实验/EX-2026-10-14-文本化.md)；
- arXiv 各分类 HTML 覆盖率 → [EX-2026-10-14-textify §3.5](实验/EX-2026-10-14-文本化.md)；
- `Q4` 是否申请 OpenAlex 免费 key → **已申请并实测**：额度 `0.1` → `1`（10×），[EX-2026-10-16-quota](实验/EX-2026-10-16-额度.md)；
- `Q20` 预算闸门 → **不做参数化预算**：改为「成本可见（返回信封带花费与是否联网）+ 余额不足降级为只查本地」（[ADR-0051](决策/ADR-0051.md)）；
- `Q22` `spec_hash` 该覆盖哪些参数 → **判据只有一条：它改不改变远端请求**。进 hash 的是声明式参数（含 `--source`、`--sort` 与将来的两个阈值），解析后的日期与 `--limit` / `--abstract` / `--in` 不进；取数固定一页 100 条，`--limit` 只管展示（[ADR-0062](决策/ADR-0062.md)）；
- `Q23` 全库清单的载荷粒度 → **清单只装可溯源最小集、摘要与正文不进载荷、不做分页/计数**（[ADR-0057](决策/ADR-0057.md)）；
- `Q24` 检索门 → **改用 `search.title_and_abstract=` 的单个布尔串**；每个值一律加引号，因此不需要转义层；结构化条件继续走 `filter=`（[ADR-0063](决策/ADR-0063.md)）；
- `Q25` venue 白名单与黑名单的判据 → **「载体 source id 集合 ∩ 名单 ≠ ∅」，两端同一判据、黑白名单只差方向；会名到 S-id 的登记表随代码进版本库；远端改用 `locations.source.id:`，给定白名单时跳过 arXiv 腿**（[ADR-0060](决策/ADR-0060.md)）；
- `Q26` 是否引入引用阈值 → **两个都做**：`--min-citations` 与 `--min-fwci`，同时给出取与，远端 filter + 本地同条件、空值不通过、跳过 arXiv 腿（[ADR-0061](决策/ADR-0061.md)；其中「排序只作用于展示」已由 [ADR-0062](决策/ADR-0062.md) 取代）；
- `Q27` L1 补桥的校验落点与顺序 → **桥是「声明」不是「标识」**：`record_ident` 区分 `ident` / `bridge`，桥可被真正的持有者接管，校验落在 `ingest()` 的 L1 分支且归组前做；存量两条反例已订正（[ADR-0064](决策/ADR-0064.md)）；
- `Q21` Crossref REST 的字段名与摘要质量 → **已实测**：六个字段的形状与文档一致，`type` 映射四种实测值也对；`title` 的 JATS 标记未剥（进 `title_key`）、剥标记后空白未折叠、`mailto` 未生效、arXiv DOI 在 Crossref 404（[EX-2026-10-16-crossref-fields](实验/EX-2026-10-16-复核Crossref字段.md)）；
- 五处实现前缺定义的契约口径（`sync` 摘要载荷、`search` 落池、`textify` 的 LaTeX 装配与 PDF 图渲染、`digest put` 的键校验、部分失败的退出码）→ [ADR-0056](决策/ADR-0056.md)。
