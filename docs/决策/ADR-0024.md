# ADR-0024　多来源并存策略

**状态**：accepted（2026-10-14）

**决策**：统统存为记录、各自保留；不做破坏性合并；由分组层（可重分组的视图）归为 work；派生数据按源文本 `content_hash` 共享，不指向"最早的那条记录"；字节按 `sha256` 内容寻址

**为什么**：写入无需跨源仲裁 → 幂等、可乱序、可并行；无不可逆操作 → 分组错了改分组；"指向最早"在原文变更时必然给出错误译文，按内容哈希则自动对且顺序无关
