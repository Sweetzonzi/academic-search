# ADR-0071　引用阈值包含下界

**状态**：accepted（2026-10-21）。取代 [ADR-0061](ADR-0061.md) 决策 2 的严格下界写法；同时给出取与、空值不通过与跳过 arXiv 的规则继续有效。

- **决策**：
  1. `--min-citations N` 表示 `cited_by_count >= N`，`--min-fwci X` 表示 `fwci >= X`；等于阈值的论文必须通过。计数是非负整数，FWCI 阈值是有限非负数，无效 CLI 输入返回 `invalid_args`。
  2. OpenAlex 下发包含下界的开放区间 `cited_by_count:N-`、`fwci:X-`；FWCI 按十进制表示，不用减 epsilon 模拟包含等号。本地继续按 `>=` 判断。
  3. 含任一引用阈值的 `canonical_spec` 增加 `min_bounds: "inclusive"`，使该查询不复用严格下界的采集新鲜度。没有引用阈值的查询不因本决策改变 hash；已有论文和账本保留，无数据库迁移。
- **理由**：`min` 表达可接受的最小值；包含下界符合使用预期，并消除刷新与本地过滤在等号处的差异。
- **依据**：开放区间与严格大于的边界差异已经真实 API 核验，见 [EX-2026-10-21-search-semantics §1](../实验/EX-2026-10-21-检索语义.md)。
- **代价**：带阈值的存量查询需要按新身份重新采集一次；新增的边界论文仍需主题相关性复核。
