# ADR-0061　找经典的阈值：`--min-citations` 与 `--min-fwci`

**状态**：partially superseded by [ADR-0062](ADR-0062.md)（2026-10-16 接受，2026-10-16 收窄：决策 5 的「`--sort citations` 保持展示排序」由 ADR-0062 决策 6 取代，其余决策继续有效）

> **范围**：本条定「找某个方向的经典」用哪种条件。机制沿用 [ADR-0060](ADR-0060.md)——两端同一条件、空值一律不通过、给定单边条件时跳过 arXiv 腿。**不给 profile 的具名查询加该字段**（画像的目的是追新，记为 [OPEN](../06-待决事项.md) 的 `Q28`）。`--sort` 是否参与远端取数仍归 `Q22`。

- **决策**：

  1. **新增两个可选参数**：`--min-citations N`（原始被引下限）与 `--min-fwci X`（领域归一化被引下限）。两者默认关闭；同时给出时取**与**。
  2. **远端**分别下发 `filter=cited_by_count:>N` 与 `filter=fwci:>X`，可与主题过滤器叠加，**不额外计费**（仍是 10 credits 一次）。
  3. **本地**用同一条件再判一次；`cited_by_count` 或 `fwci` 为空即不通过。
  4. **给定其中任一条时跳过 arXiv 腿**（arXiv 侧无被引数据）。
  5. **`--sort citations` 保持展示排序**，不参与远端取数。

- **理由**：

  1. **「找经典」现在端到端不通。** 远端恒按日期降序取回，本地 `--sort citations` 只能重排已取回的那批（[EX-2026-10-16-source-contract](../实验/EX-2026-10-16-检索口径与来源校验.md) §4）；库里被引 ≥100 的 20 条全是 `lookup` 按已知 ID 逐条补进来的。
  2. **两个阈值各有分工。** 原始计数直观，但随领域漂移——`"world model"` 的 14 582 条命中里 `>100` 只剩 294；`fwci` 以「领域同年平均 = 1」为尺度，跨领域不用重新猜阈值。两者实测都能进 `filter=`（同 §12(a)：`fwci:>2` 2 103 条、`fwci:>3` 1 579 条）。
  3. **本地判定不需要新增存储。** `fwci` 与 `citation_normalized_percentile` 本来就在 `record` 表里，`parse_work()` 已经在写；`cited_by_count` 的 work 级聚合已经是 `max`。
  4. **不引入新概念。** 与 [ADR-0060](ADR-0060.md) 同构（远端 filter + 本地同条件 + 空值不通过 + 跳过 arXiv 腿），实现上是同一条判据管线加两个数值字段。
  5. **指标本来就在设计里。** [DESIGN §4.1](../02-设计说明书.md) 的质量闸门点名的就是 `fwci` 与 `citation_normalized_percentile`；[ADR-0051](ADR-0051.md) 顺延的是 A/B/C 分级与 `--min-grade`，不是这两个指标。

- **否决**：

  - **用远端 `sort=cited_by_count:desc` 代替阈值**：实测排在最前的是跨领域的短语命中——1971 定理证明、1997 社会学、2006 脑网络（同 §12(b)(c)）。它排的是全局被引，不是领域内重要性；而且真推给远端之后，远端会从全部命中里挑被引最高的一批，取回的正是那几条。
  - **只做 `--min-citations`**：跨领域查询要重新猜阈值，而 `fwci` 的尺度是自解释的。
  - **只做 `--min-fwci`**：`fwci` 是 OpenAlex 的加工指标，直观性差；且新论文与部分类型没有该值，只留它会让「被引 100 次以上」这种直白诉求无处表达。
  - **白名单式 fail-open**：会让 arXiv 侧 778 条记录无条件通过，阈值等于不筛。
  - **同时暴露 `citation_normalized_percentile`**：它与 `fwci` 讲同一件事（分位数 vs 均值倍数），一次给三个只会让人犹豫用哪个。列已经在表里，将来要换按新 ADR 走。

- **代价**：

  1. **`fwci` 覆盖不完整**：很新的论文与部分类型没有该值，按「空值不通过」会被整批排除；`--min-fwci` 因此偏向有一定年头的文献。这与「找经典」的用途一致，但要在文档里写明。
  2. **两个参数都改变远端取数**，按 `Q22` 待定的规则应进 `spec_hash`；`Q22` 定完之前不写死，否则会重演「同一检索式在窗口内不重复计费」这条判断失准。
  3. **给定阈值时跳过 arXiv 腿**：「尚未进 OpenAlex 的高被引预印本」取不到。这与 [ADR-0060](ADR-0060.md) 决策 5 的取舍同源。
  4. **阈值是下限，没有上限**：出现「只要 N 附近」的真实用法时要另加参数。

- **触发重估的信号**：① 出现「`fwci` 覆盖不足导致漏掉明显该入选的论文」的真实案例；② `Q22` 定完后 `spec_hash` 的变体数超出可接受范围；③ 出现需要上限或区间的真实用法；④ OpenAlex 改变 `fwci` 的口径或弃用该字段。
