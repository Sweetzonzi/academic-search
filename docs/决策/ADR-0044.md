# ADR-0044　候选池不设状态机

**状态**：accepted（2026-10-15）

> **范围**：本条决策 4 的 A/B/C 分级与 `--min-grade` 过滤**不在初版**（[ADR-0051](ADR-0051.md)）——初版只做 `is_retracted`、`paratext` / `erratum` 与掠夺性期刊黑名单这类纯规则硬排除；决策 1 的两个时间戳列保留，但初版没有写入入口，也不做相应过滤。

- **决策**：
  1. **`candidate` 表没有状态列**：一行代表"这个 work 入过池"，**行存在本身就是事实**。「要不要」用两个可空时间戳表达——`dismissed_at`（空 = 没表过态；非空 = 不要）与 `dismissed_until`（空 = 永久；非空 = 到期后允许重新浮现）。**不设 `new` / `promoted` / `parked` / `hidden` 枚举。**
  2. **"已入 Zotero"由 `zotero_link` 行的存在表达**（一个 work 一条）；用户删除条目后记 `zotero_link.removed_at`，不自动重新入库。
  3. **不引入"收藏"标记**：表达"我要"的现有方式是 `textify`（证据是 `artifact` 有行）与 M5 的 `promote`；需要轻量正向标记时另行评估。
  4. **质量分级留在库里，过滤在读取端**：分级（A/B/C）与理由随候选落库，**不做写入期淘汰**；`search` 默认按质量下限过滤（默认 `B`，`--min-grade A|B|C` 放宽，阈值可由 `config/search.toml` 覆盖），掠夺性期刊黑名单**无条件排除**。`sync` 的报告与推荐清单按同一阈值过滤，但 `run.json` 记录各级计数——**数据不丢，可见性可调**。
  5. **边界**：`candidate` 只装"入过池"与"表过态"两个事实，不得长出 collection、标签树或引用格式化（[ADR-0032](ADR-0032.md)）。

- **理由**：
  1. **状态机承担的只有一件事**。防重复计费靠 `record` / `record_ident` 的唯一约束；全文取没取靠 `artifact` 行的存在（[ADR-0035](ADR-0035.md)）；枚举剩下的作用只是"推不推给你"。
  2. **"推"在定时那条线上已由 `run_id` 解决**（[ADR-0028](ADR-0028.md)：「新发现」= 本次才入池）。枚举的边际价值只剩交互式检索的显示过滤，不值得一台状态机。
  3. **状态有维护成本**：`candidate` 是 work 级，而 work 会重分组（合并 / 拆分，[ADR-0003](ADR-0003.md)），每次重组都要搬状态；再加上"谁设置""什么时候过期"两套规则。
  4. **分级随信号变化**：引用数与 FWCI 会变，分级要重算（[DESIGN §4.3.9](../02-设计说明书.md)）。把"不给看"写死在写入期，就永久失去"以后放宽"的能力；放在读取端则只是一个参数。
  5. **稀缺资源是 LLM 的上下文，不是磁盘**：内容寻址去重后，多存一级的边际成本接近零，所以策略是**存宽、取严**。

- **否决**：
  - **四态枚举**（`new` / `promoted` / `parked` / `hidden`）：`new` 与"入过池"是同义反复，`promoted` 与 `zotero_link` 的存在是同义反复，`parked` 与 `hidden` 的差别只是有效期长短——一条枚举里有两组同义项；
  - **写入期就把低分级结果丢掉**：与"不做二元淘汰"相悖，且丢掉了调参与复盘要用的信号；
  - **`starred_at` 收藏标记**：初版里"要过"已能由 `artifact` 表达，正向标记会引出"收藏夹算不算 collection"的边界问题。

- **代价**：
  1. **"这篇别再给我看"要显式说一次**，没有"LLM 初筛自动压下去"的效果；未被 dismiss 的旧论文仍会在交互式检索里出现。
  2. **默认质量阈值 `B` 是估计值**，待真实语料校准。触发重估信号：① 检索结果里反复出现明显该被排除的 venue；② 有分级的论文在 B 与 C 之间大量堆积。
  3. **`dismissed_until` 到期后自动重新浮现**需要一次判定；实现时注意它不参与任何幂等键。
