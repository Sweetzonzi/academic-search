# ADR-0053　输出载荷与读取定位

**状态**：accepted（2026-10-15）

> **取代**：决策 2 里「投影缺失时报 `projection_missing` 并提示重跑 `textify --work`，不隐式写盘」由 [ADR-0067](ADR-0067.md) 取代——`read` 缺正文时会懒物化（先本地重投影、再取件转换），`projection_missing` 只在「不许联网且取不到」时出现。「全文不进信封、`read` 是定位器」不变。

- **决策**：
  1. **载荷契约独立成文**：新增 [IFACE-PAYLOAD](../接口/输出载荷.md)，定义结果条目字段集、`run.json` schema、`error.code` 表、`digest` 载荷、`read` 载荷与全部机器枚举值。[IFACE](../03-接口契约.md) 只留信封与命令，链接过去；`SCHEMA_VERSION` 的「只增不删」对象就是这份文档。
  2. **`read` 改为定位器**：不再返回全文，而是返回
     - `doc.path`：**`bytes/` 里的 `paper.md` 路径**（权威、保证存在；库里存的是 `sha256`，路径现场拼，**不落库**）；
     - `doc.work_path`：`works/<work_key>/` 投影路径，**仅当投影存在时**附带（人读与相对引用可用）；
     - `figures[]`：Markdown 里的图件引用名 → `bytes/` 路径 + 图注（否则从 `bytes/` 读时相对路径 `figures/…` 会断）；
     - `anchors[]`：章节或页码锚点 → **行号**（与路径同源于同一个 `sha256`）。
     投影缺失时报 `error.code=projection_missing` 并提示重跑 `textify --work`，**不隐式写盘**。
  3. **排序**：默认按 `published_at` 降序（新论文优先），`--sort citations|date` 可切；**`candidate.score` 与 `grade` 初版都不写**——「质量判断」这一面整体顺延（[ADR-0051](ADR-0051.md)）。
  4. **检索参数口径**：`--limit` 默认 20，作用于**合并去重后的 work 数**（不是每源）；`--in body` 的命中返回前后各 2 行、每篇最多 5 处；`--source` 在 `config/sources.toml` 的启用集内收窄，初版取值为 `openalex` / `arxiv`（Crossref 只在 `lookup` 内部兜底）。
  5. **枚举机器值统一落 IFACE-PAYLOAD**：`artifact.kind`、`record_ident.ns`、`derived kind`、`lang`、`error.code`、`run.status`、`record.status`、`work_member.role`。

- **理由**：
  1. **信封有家、载荷没有家**：这是本轮缺口的根——`{ok, command, schema, data}` 定义了外壳，`data` 里装什么全靠实现者即兴；而它正是唯一对外承诺稳定的部分。
  2. **`bytes/` 路径不违反「路径不落库」**：库里存的仍是 `sha256`，`bytes/<前2位>/<sha256>` 是内容的函数、可现场拼，而且比 `works/` 路径**更稳**（后者被明令不得长期保存、投影删掉就不存在）。`works/<work_key>/paper.md` 只是同一份字节的硬链接，内容完全一致。
  3. **全文不该走 CLI 信封**：长论文一次吞吐几万 token，会把对话上下文吃满；agent 用自己的文件工具读（可 offset/limit 分段）更省、更可控。
  4. **图件映射是必须的配套**：`paper.md` 用相对路径引用图件，从内容坐标读时那个相对路径无效，不给映射就等于丢图。
  5. **排序不引入自造指标**：分级顺延之后若再自造加权 `score`，等于用一个未标定的数字决定可见性；「新论文优先」直接满足定时场景，交互场景用 `--sort citations` 即可。

- **代价**：
  1. **调用方多一步**：读全文要「`read` 拿路径 → 用文件工具读」，比一条命令拿全文多一跳。
  2. **行号是版本相关的**：锚点行号只在返回的那个 `sha256` 上有效；产物重新生成后要重新取定位（路径与行号同源，所以不会指错版本，只会过期）。
  3. **`--sort citations` 对非 OpenAlex 记录无效**：那些记录没有引用信号，会排在后面。
  4. **`--source` 不能绕过配置**：临时想试一个被关掉的源，得先改 `sources.toml`。

- **触发重估的信号**：① agent 反复因为「多一跳」而读错文件；② 图件映射在真实语料上出现对不上的引用；③ 出现「按质量排序」的真实需求（届时与分级一起做）。
