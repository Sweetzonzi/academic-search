# ADR-0009　「我的库」抽象为 `LibraryBackend`，Zotero 是默认实现而非唯一实现

**状态**：accepted（2026-10-14）

- **决策**：定义 `LibraryBackend` 接口，提供三种实现——`ZoteroBackend`（sqlite 只读副本 + Zotero 官方 API 写）、`FileBackend`（本地 `library/*.md`，YAML front-matter + BibTeX 导出）、`None`（只用语料库）。「我的库」是逻辑概念，**权威随后端而定**。
- **理由**：课题组成员研究方向不同，只需"同一套工具"，不要求同一套文献管理器；把库抽象成接口后工具才能真正分发，而不必强制每人安装并配置 Zotero。
- **否决**：强制所有人用 Zotero（分发门槛高）；只做 Zotero 后端（等于把工具绑定到单一产品）。
- **代价**：多一层抽象与两套后端测试；去重第一层按后端分别实现（读 sqlite 副本 / 读 YAML），但共用同一套 `identifiers.py` 归一化函数。
