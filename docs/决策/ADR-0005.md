# ADR-0005　调度器中立：只约束命令的性质，不规定用哪个调度器

**状态**：accepted（2026-10-14）

- **决策**：采集入口是一个**无头、幂等、可观测**的 CLI 命令；调度由使用者的现有工具承担——**DSH schedule、Codex 等外部 agent 工具的定时任务、系统计划任务任选，可组合**。
- **理由**：调度是部署选择而非设计约束。只要命令无头、可重入、产物是结构化报告，任何调度器都能驱动它、任何 agent 都能读它。
- **约束三条**：① 无头（不依赖 GUI/TTY/交互）；② 幂等（同参数重跑不产生重复候选与重复入库）；③ 可观测（每次运行产出 `run.json` + markdown 报告）。
- **否决**：把采集逻辑做进某个特定 agent 的会话内（换 agent 就得重写）；要求人在触发点确认（破坏无人值守）。
- **代价**：需维护 run 账本与报告格式稳定性（`SCHEMA_VERSION` 只增不删）。
