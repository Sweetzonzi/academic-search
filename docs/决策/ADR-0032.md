# ADR-0032　初版范围：LLM 检索缓存层；Zotero 桥接整体顺延到 M5

**状态**：accepted（2026-10-15）

> **取代**：本条中"初版（M0–M4）"的范围口径由 [ADR-0046](ADR-0046.md) 取代——初版为 M0–M3，引用图谱（M4 的 `graph`）在初版之外；"不接 Zotero、与库相关的读写顺延到 M5"的结论不变。

> **取代**：本条中"「我要这篇」只能表达为候选池的一个状态"一句由 [ADR-0044](ADR-0044.md) 取代——「要这篇」= `textify`，候选池不设状态；其余范围结论不变。

> **取代**：本条中"初版交付物是六条命令"的清单口径由 [ADR-0051](ADR-0051.md) 取代——初版命令面为六条用户命令 + 三条支撑命令（`sync` / `verify` / `profile`），其中 `export` 初版不实现（契约保留、验收顺延），`bundle` 是它的别名。

- **决策**：初版（M0–M4）**不接 Zotero**，交付物是一个「LLM 用的文献检索缓存层」——`search` / `lookup` / `textify` / `digest` / `read` / `export` + sidecar 缓存 + 薄 `SKILL.md`。Zotero 的读取与写入桥接（升级 10.x、本地写入授权、`promote`、child note 写回、`.zotero-ft-cache` 通道、连接器回退）整体移到 **M5**，作为独立里程碑。

- **理由**：
  1. **写入通道是纯成本**：需要 Zotero 10+、弹窗授权、`Zotero-Server-ID` 版本语义、无跨库事务。初版接它换不到任何东西。
  2. **读取通道在初版几乎不产生价值**：本机「我的库」只有 5 条顶层条目（[RUN-M5 §1](../运维/M5-Zotero桥接.md)）。它回答的是「别重复推荐我库里已有的」，而库里的条目要靠 `promote` 才积累——初版不写入，读也读不到东西，是循环依赖。
  3. **核心性质不依赖 Zotero**：「先本地去重再联网」的「本地」本来就是 sidecar——`record` 持久化上一次 run 的记录，`candidate` 持久化「看过但不要」。M1 的验收判据「同一查询重跑 0 条重复候选」只靠 sidecar 就能过。Zotero 只是额外一层「用户人工策展库」。
  4. **全文通道的主线不是它**：全文来源优先级里 `.zotero-ft-cache` 是第 ② 位，第 ① 位（arXiv LaTeX 源码 / HTML）本来就是主线（[DESIGN §4.10](../02-设计说明书.md)）。
  5. **省下的是最不确定的部分**：M0 从「升级 + 授权 + 写读删」的半天降为 1 小时的额度实测；M2 去掉 `promote`、child note 与 ft-cache 后从 3–5 天降为 1–2 天，且不再有「升级不可逆」这类风险。

- **代价**：
  1. 少了 `.zotero-ft-cache`（零成本纯文本通道）→ 只有 PDF、没有原生文本的老论文回落到 PDF 自解析。可用样本本来就小（本机 6 个附件）。
  2. 蹭不到 Zotero 的全文索引（`qmode=everything`）→ **正文检索必须自己解决**，不能像原计划那样借用 Zotero 的全文索引（方案见 [ADR-0036](ADR-0036.md)）。
  3. 初版里用户没有「条目」这个实体：中文摘要留在 sidecar，正文留在 `works/`，在 Zotero UI 里看不到。交接靠 `export`（BibTeX / RIS / CSL JSON）。

- **不动的部分**：本决策**不推翻任何既有 ADR**。[ADR-0001](ADR-0001.md) 三层存储、[ADR-0008](ADR-0008.md) 权威归属、[ADR-0009](ADR-0009.md) `LibraryBackend` 抽象、[ADR-0013](ADR-0013.md) 无 Zotero 也能跑——**设计一字不改，改的只是先做哪一步**。

- **边界（防止 sidecar 悄悄变成「我的库」）**：初版里「我要这篇」只能表达为**候选池的一个状态**，不是条目库。禁止在 sidecar 里长出 collection、标签树、引用格式化——那是 Zotero 的职责（[ADR-0008](ADR-0008.md)）。初版没有「我的库」，「我的库」在 M5 之前是**空的**。

- **翻转条件**：若实际使用中发现「没有条目实体」成为主要摩擦（例如频繁需要按标签筛自己的收藏），提前 M5；若发现用户根本不打开 Zotero，则按 [ADR-0008](ADR-0008.md) 的翻转条件重新评估权威归属。
