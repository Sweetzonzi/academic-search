# ADR-0018　归一化层

**状态**：accepted（2026-10-14）

**决策**：必需，且是产品的一部分：公式环境拆壳 → 图件 HTML→Markdown 图片 → PDF 图转 PNG → 锚点注入 → 交叉引用解析

**为什么**：pandoc 原始输出实测不可直接使用：8/8 篇出现非法 `$$\begin{equation}…$$`、图件全部是带绝对路径的 raw HTML
