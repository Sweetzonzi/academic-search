# ADR-0002　采用「确定性 CLI + 薄 SKILL.md」，而不是常驻 MCP

**状态**：accepted（2026-10-14）

- **理由**：分页、限流、去重、幂等、事务、预算应由代码保证，LLM 只做查询扩展、筛选与总结；上下文成本上 MCP 约 13,448 tokens/请求，而 skill 目录仅 frontmatter 约 98 tokens、正文按需 1,368（[REF-DSH](../调研/DSH能力.md)）。
- **否决**：MCP server（低频高价值场景常驻代价过高）；"把逻辑写进 SKILL.md 让 LLM 自行编排"（不可复现、不可测试、易烧额度）。
- **代价**：需维护 CLI 参数、JSON 契约与退出码约定。
