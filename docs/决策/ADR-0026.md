# ADR-0026　分组维护

**状态**：accepted（2026-10-14）

**决策**：分组任务常走 OpenAlex 单实体 GET（`/works/doi:<doi>`，免费）拿 `locations[]` 做 arXiv↔正式版桥；合并时自己保留 `merged_into` 映射

**为什么**：单实体 GET 与 4xx/5xx 免费，所以分组/对账任务可以高频跑而不烧额度；保留合并映射正是我们批评 OpenAlex 缺失的那一点
