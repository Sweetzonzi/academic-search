# ADR-0021　两条路线的关系

**状态**：accepted（2026-10-14）

**决策**：LaTeX 源码为主，HTML 为辅（回退 + 补表号表题 + 取 SVG 图）。HTML 不作为主力

**为什么**：实测：HTML 的数学里会出现未展开的自定义宏（`\real^{n}` 这类无法渲染的命令，单篇 83 次），而 LaTeX 路线 8/8 篇宏展开全对、体积只有 60%。清洗后 HTML 仍为 1.65 倍体积
