# ADR-0031　范围：综述取材在内，撰写与聚合产物在外

**状态**：accepted（2026-10-15）

> **范围**：本条决策 ① 里的"可导出为写作素材"依赖 `export`，而 `export` 初版不实现（[ADR-0051](ADR-0051.md)）——初版只能给出清单、来源与摘要，导出能力顺延。

- **决策**：① **综述取材在内**——给定领域或主题，列出既有论文清单（本地语料优先，缺口才联网），带来源、入库状态与中文摘要，可导出为写作素材；② **不代写综述**——工具不产出综述正文，论证、取舍与写作由人完成；③ **系统综述的检索方法学不在范围内**（检索式留档、纳排计数、PRISMA 流程）；④ **聚合产物不进 v1**——领域地图、主题差分、跨篇对比都等 M1 有真实语料后再评估。
- **理由**：① 系统综述要求「穷尽 + 检索可复现」，与「每日额度 $1 + 质量闸门精选」的定位正面冲突；② 聚合产物要先知道真实语料的规模与主题分布才有意义，而额度是否够支撑探索式检索尚未实测。
- **否决**：**v1 一并做领域地图**——探索陌生领域能立刻用，但会挤占 M1 的工期与额度；**v1 全进**（地图 + 差分 + 对比表）——探索、热点、综述素材一次到位，代价是额度与工期双重超支。
- **代价**：「了解陌生领域」与「追研究热点」两类需求在 v1 只能靠「清单 + 人工读」近似满足。
