# ADR-0006　默认**不下载 PDF**，按需获取，且只取 OA 版本

**状态**：accepted（2026-10-14）

- **理由**：元数据 + 摘要足以支撑检索、去重与初筛；避免版权风险、存储膨胀与"两份 PDF 不知哪份是新的"。
- **否决**：全量预下载（成本与合规风险）；完全不下载（精读需要正文）。
- **代价**：精读时一次网络往返；OA 覆盖不足时可能取不到全文（记录原因即可）。
- **落地形态**：promote 出来的是**仅元信息条目**（§4.3.8）；PDF 在首次精读时挂到**同一个条目**上。
