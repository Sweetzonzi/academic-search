# ADR-0010　全文文本化：原生文本优先 + 随附便携 pandoc + 图随文保存

**状态**：accepted（2026-10-14）

- **决策**：为 LLM 阅读生成 Markdown，优先走**原生文本源**（arXiv LaTeX 源码 → arXiv/出版社 HTML），PDF→MD 仅作回退；转换器**随工具附带便携 pandoc**；**图件随文落盘并在 Markdown 中相对引用**；转换时**注入锚点**（详见 §4.10）。
- **理由**：本领域论文公式密集，PDF→MD 的公式与双栏排版最易损坏，而 arXiv 实测同时提供 HTML 与 LaTeX 源码；图从原生源取得是矢量/高分辨率原件，优于从 PDF 抠图；锚点是 R7 溯源的前置条件。
- **否决**：只用 PDF→MD（公式失真）；只存文本不存图（看图要重新下载）；把 Markdown 直接塞进 Zotero（不可索引、不可标注、吃同步配额）。
- **代价**：随工具多约 30–50 MB 的 pandoc（`pypandoc_binary` 实测下载 40.9 MB / 解压后 pandoc.exe 221 MB）；需维护正文容器选择器与锚点映射；**pandoc 的原始输出必须经过归一化层**（[05](../实验/EX-2026-10-14-文本化.md)）。
