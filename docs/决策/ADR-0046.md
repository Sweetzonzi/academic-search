# ADR-0046　初版范围收在 M0–M3

**状态**：accepted（2026-10-15）

> **范围**：本条理由 2 的「六条命令」清单口径由 [ADR-0051](ADR-0051.md) 取代——初版命令面为六条用户命令 + 三条支撑命令（`sync` / `verify` / `profile`），`export` 初版不实现；"引用图谱不在初版"的结论不变。

- **决策**：**初版 = M0–M3**。引用图谱与研究脉络（R10、S6 与 M4 的 `graph` 命令）**不在初版**，列为初版稳定后评估的可选项；M5（Zotero 桥接）同样在初版之外。
- **理由**：
  1. **R10 自身的定性就是远期**：需求写"未来……研究脉络可视化，顺着引用找上去"，判据标**远期验收**；交互场景 S6 标**（交互，远期）**；[DESIGN §4.8](../02-设计说明书.md) 的节标题是"（未来，R10）"。
  2. **初版交付物清单不含它**：`search` / `lookup` / `textify` / `digest` / `read` / `export` + sidecar + 薄 `SKILL.md` 是初版对外承诺的六条命令，`graph` 不在其中（[ADR-0032](ADR-0032.md)）。
  3. **它是唯一依赖引用边抓取的功能**：初版其余功能都不需要 `citation_edge` 表，也不需要 `filter=cites:` 的分页抓取与节点裁剪策略。
  4. **与既有取舍一致**：[ADR-0031](ADR-0031.md) 已把"了解陌生领域""追研究热点"这类需要聚合产物的能力排除在 v1 之外；引用图谱是更强的聚合，不应反而留在 v1。
- **代价**：
  1. R10 的验收要等到 M4 才能谈，"顺着引用找上去"在初版不可用。
  2. `graph` 在接口契约里保留命令形状，实现整体后移。
- **触发重估的信号**：初版（M0–M3）稳定后，若出现"要看某个方向的演进主线"的真实请求，或在写综述 / 相关工作章节时反复手工追溯引用，即启动 M4。
