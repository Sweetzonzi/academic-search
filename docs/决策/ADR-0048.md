# ADR-0048　初版只自动执行 L0/L1

**状态**：accepted（2026-10-15）

- **决策**：初版的 `group()` **只自动执行 L0（共享强标识）与 L1（显式桥）**。**L2 命中不归组**，登记为待确认（`dup_suspect`），并在检索结果里标注"可能同一篇"；L3（人工确认）初版不提供入口（[ADR-0047](ADR-0047.md)）。
- **理由**：
  1. **没有修复路径时，误合不可逆**：L2 的实测假阳性约 4%（[DESIGN §4.2.3](../02-设计说明书.md)），而人工拆组已不在初版（[ADR-0047](ADR-0047.md)）。[ADR-0011](ADR-0011.md) 理由 4 的代价不对称性在这里生效——**漏合只是浪费、可修；误合会让两篇的 `paper.md`、图件、译文、引用边互相静默覆盖**。
  2. **漏合的表现是"同一篇两条"，不是错误**：两条记录各自保留、各自可读，人一眼能看出重复；代价只是候选池里多一条。
  3. **L0 / L1 已覆盖绝大多数真实重复**：DOI、arXiv ID、OpenAlex W、PMID 这些强标识，加上 `locations[]` / `externalIds` 的显式桥，正是预印本↔正式版的主要通道（[ADR-0026](ADR-0026.md)）。
- **代价**：
  1. **通不过强标识与桥的重复会各占一条 work**：例如只有 Crossref 记录、OpenAlex 侧又查不到桥的论文。检索结果里同一篇可能出现两次，带"可能同一篇"标注。
  2. **`dup_suspect` 会长期存在**：必须在结果里给出查看途径（标注即可），否则登记没有意义。
- **触发重估的信号**：① 实际语料显示 L2 的命中多为真重复、假阳性远低于实测的 4%；② 引入人工确认入口（[ADR-0047](ADR-0047.md) 的重估条件）后，可恢复 L2 自动归组并由人兜底。
