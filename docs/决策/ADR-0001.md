# ADR-0001　采用「Zotero + sidecar + blob 目录」三层存储，而不是单一存储

**状态**：accepted（2026-10-14）

- **理由**：Zotero 的 `itemData` 是固定字段集 EAV，**结构上装不下**"中文摘要 + 模型版本 + 源哈希"这类任意派生字段；候选池、评分、引用边属于"工作台状态"，不该成为用户资产。
- **否决**：① 全部塞进 Zotero（`Extra`/笔记）→ 污染库、无类型化列、无法 SQL 查、随导出泄漏（[REF-ZOTERO §3](../调研/Zotero能力.md) 证实 Extra 会被解析）；② 自建完整条目库 → 违背 R8。
- **代价**：多一个文件与一层 join；需要"权威边界"纪律（§4.3.2）。
