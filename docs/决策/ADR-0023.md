# ADR-0023　作品身份：确定性 id，不铸随机 id

**状态**：accepted（2026-10-14）

**决策**：全库没有任何随机生成的标识符：`record_uid` 由 `(source, source_id)` 确定性派生，公式见 [IFACE-STORE §1](../接口/存储与迁移.md)（确定性、可复现、路径安全）；`work_key` 直接取组内最早那条记录的 `record_uid`，不另铸 id；第三方 ID（OpenAlex `W…` / DOI / arXiv）一律降为 `record_ident` 别名。配三条首领规则：首领=最早记录、禁止硬删记录（标 tombstone）、合并=重定向不改名

**为什么**：实测**被合并/删除的 OpenAlex Work ID 返回 404 且无跳转**（官方删除日志 5,231 万条中取 5 个真实 ID 复测），2025 年后不再提供"旧 ID→新 ID"映射；标题哈希跨来源碰撞 **16%（最大 7 篇同名）**、反向 1/3 标题会变。**身份的可复现性是收益**：两台机器与删库重建后，`record_uid`、`work_key`、`works/` 路径全都一致（随机 id 做不到）
