# ADR-0074　read 的转换清单、离线物化与缺损提示

**状态**：accepted（2026-10-22）

**范围**：arXiv LaTeX 源码与 HTML；不解析本地 PDF、扫描件或出版社页面。源码中的 PDF 图仍可渲染成 PNG。

## 1. 决策

1. **一次转换是一组产物**。`artifact.kind` 增加 `paper_manifest` 与 `source_media`。清单是存入 `bytes/` 的 JSON，关联原件的 kind / sha256、转换器版本、正文 sha256、图件相对引用与 sha256、图注、HTML 原始媒体的 URL 与 sha256、元信息及缺损提示。清单自身以 `paper_manifest` 登记；正文、图件、图注与原始媒体也分别登记。清单只存哈希与包内相对引用，不存本机路径。读取与重建只能使用同一清单内的成员，不按记录拼凑不同转换的图件。
2. **缓存选择**。默认使用最近成功登记且成员完整的清单；元数据版本变化只产生 `stale`，不发请求。本地已有该路线的新原件，或可用转换器版本变化时，从本地原件重转。缺转换器但已有完整清单时仍可读取，并提示未检查转换器更新。`--refresh false` 同样允许本地转换；无可用正文且本地不能转换时报 `projection_missing`，绝不联网。`--refresh true` 更新原件后转换，不能用旧正文掩盖刷新失败。它明确了 [ADR-0067](ADR-0067.md) 决策 2/5 的优先级：默认不追远端版本，显式刷新允许更新；原件或转换器变化使派生缓存失效。
3. **取件与转换分开**。转换步骤接受已下载的源码或 HTML 字节。LaTeX 下载失败或转换失败均可回退 HTML。HTML 媒体优先复用同一份 HTML 原件对应的清单缓存；离线缺媒体时保留正文并标注缺图，不能偷偷联网。每条路线使用独立临时目录，失败路线的图件不进入成功清单。
4. **缺损可见**。空正文或所有路线转换失败属于失败；缺图、未解析引用、PDF 图未渲染属于成功但有 `warnings`。HTML 路线固定提示自定义宏与公式布局未完全验证；不承诺公式经过实际渲染校验。正文中缺失的图片引用改为缺图说明，不留下失效的临时路径。有已知缺损时，agent 必须说明并回查原件，不能把转换成功视为内容完整。
5. **写锁与账本**。`read` 在取件、转换与投影前取得写锁，冲突直接报 `busy`。一次 `read` 只记一条 run，包含回退、媒体请求及失败；可复用的原件即使转换失败也保留登记。清单最后登记，未完成的转换不能被选为缓存。最近登记按登记顺序选择，重复登记已有哈希也更新选择顺序。
6. **定位器**。载荷定义以 [IFACE-PAYLOAD §5.2](../接口/输出载荷.md) 为准。章节行号从最终落盘的正文计算，源码锚点是章节定位，不是假定的 PDF 页码；`figures[].ref` 在同一清单中解析。`source_version` 与 `remote_version` 各自保留已知值，未知的一侧为 `null`；只有两侧均已知且不等时 `stale=true`。

## 2. 验收

离线测试覆盖首次转换、缓存命中、投影重建、原件与转换器变化、版本未知、HTML 回退和缺图、图件跨版本隔离、刷新失败、写锁及账本。真实 pandoc 验收覆盖源码和 HTML 的正文、公式、章节与图件；网络取件与论文阅读的实测范围另记实验，不能用桩客户端证明网络可用或公式渲染正确。
