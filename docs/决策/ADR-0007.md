# ADR-0007　检索入口唯一：`search` / `lookup --scope auto`，内部固定三段顺序

**状态**：accepted（2026-10-14）

- **理由**：分叉的真正风险是"两个入口"或"同一事实能改两处"；唯一入口 + 按字段划分权威可消除该风险，同时保留"联网前先查本地"的初衷（R9），且本地查询零网络、零费用、毫秒级。
- **否决**：让 agent 分别查询 Zotero 与 sidecar 再自行合并；把本地库镜像进 sidecar 当权威（变成影子库）。
- **代价**：CLI 需实现多后端聚合与结果标注（§4.3.4）。
