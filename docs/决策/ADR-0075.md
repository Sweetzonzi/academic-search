# ADR-0075　宿主技能默认链接到仓库

- **决策**：宿主的 skill 安装项默认链接到仓库中的薄 bundle，技能文本、参考和启动器共享一份源文件；Windows 使用目录联接，POSIX 使用符号链接。不支持链接的宿主可显式使用复制模式。安装选项、目标目录、绑定顺序与迁移步骤统一见[初始化参考 §1](../../skills/academic-search/references/setup.md#1-安装与路径绑定)。本决定替代 [ADR-0055](ADR-0055.md) 决策 3 中每个宿主各存一份技能文本的要求，代码和数据仍保留在仓库。
- **理由**：复制安装在仓库技能修改后需要再次同步，容易让 agent 读取过期流程或启动器。目录链接同时覆盖文件修改、原子替换和新增文件，无需为每次修改重复安装。
- **迁移**：已有安装项先备份到技能扫描根之外；链接到其他仓库或绑定冲突时，只有显式改绑才替换。链接创建失败不自动退回复制，发布安装项失败时恢复原安装。
- **代价**：链接依赖仓库位置，移动仓库后要重新安装；文件系统中的链接成功不能证明宿主已刷新技能目录。各宿主是否识别链接需分别确认。
- **依据与验证**：
  - **官方文档**：[Codex 技能说明](https://learn.chatgpt.com/docs/build-skills) 明确支持扫描链接的技能目录并检测变动；未出现时可重启 Codex。
  - **进程与文件系统测试**：`tests/test_install_skill.py` 验证链接更新、复制迁移、备份、改绑保护与失败恢复；`tests/test_launchers.py` 验证从无关 cwd 通过链接入口定位仓库，无需 `root.txt`。
  - **本机实测（2026-10-28）**：Codex 与 DSH 的用户级安装项均已建立指向本仓库的目录联接，安装器 `--check` 通过；Codex 链接入口 `--diagnose` 返回 `stage=launcher_ready`，DSH 链接入口 `version` 返回 `ok=true`。这些检查不证明两个宿主的技能选择器已经识别链接；未验证联网。
