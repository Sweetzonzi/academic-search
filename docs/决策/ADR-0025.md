# ADR-0025　去重判据

**状态**：accepted（2026-10-14）

> **范围**：判据本身不变；初版只自动执行 L0 / L1，**L2 命中登记为待确认、不自动归组**（[ADR-0048](ADR-0048.md)），**L3（人工确认）不提供入口**（[ADR-0047](ADR-0047.md)）——`work_key` 是哈希样标识，人工操作要先做成可读清单。

**决策**：强标识（L0）> 显式桥 `locations[]`/`externalIds`（L1）> `title_key + 一作姓氏 + 年份[-1,+10]` 且强标识不冲突（L2）> 人工（L3）。`title_key` 绝不进唯一约束

**为什么**：实测假阳性：`title_key` 单独 16%、+年份 4%、+作者+年份 4%；年份窗口必须不对称（实测有 -1 与 +3 的真实例子）
