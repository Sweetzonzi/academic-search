# ADR-0003　作品身份：`record_uid` 确定性派生；`work` 直接以**首领记录的 `record_uid`** 为键；第三方 ID 只作别名

**状态**：accepted（2026-10-14）

- **决策**：分三层，且**没有任何随机铸造的 id**——
  - **记录层 `record`**：任何来源命中都写一行，键 `(source, source_id)`，原始元数据原样保留，**只增不改**；其对外 id 为 `record_uid`，公式见 [IFACE-STORE §1](../接口/存储与迁移.md)（定长、路径安全、**可复现**）。
  - **分组层 `work`**：一组记录 = 一篇作品。**`work_key` 直接取组内"最早见到"的那条记录的 `record_uid`**，不另铸 id；分组是**可随时重新分组的视图**。
  - **标识层 `record_ident`**：OpenAlex `W…` / DOI / arXiv ID / PMID / S2 CorpusId 全部是**别名**，`(ns, value)` 唯一，回答"这条网络结果记过没有"——一次索引命中。
- **理由**：
  1. **record 的身份就是它的来源坐标** `(source, source_id)`，这个事实永不改变 → 派生值永不改变，因此**可以**确定性派生。派生在这里只是**格式归一化**（单列、定长、路径安全），不是去重手段。
  2. **work 的身份是一个会被修改的分组决定**，无法从任何稳定量派生；但它**也不需要铸造**——用首领记录的 `record_uid` 即可，因为"最早见到的那条"在常态路径（新记录加入）下不会变。
  3. **收益：整个身份层可复现。** 两台机器看同一批来源 → 同样的 `record_uid`、同样的 `work_key`、同样的 `works/` 路径 → 导出文件天然对得上；**删库重建后 id 与路径完全一致**。随机 id 做不到这一点，而它换来的只是"work 与 record 概念上彻底解耦"，当前需求用不到。
  4. 第三方 ID 仍不能当主键：实测被合并/删除的 OpenAlex Work ID **返回 404 且无 `Location` 头**（官方删除日志 5,231 万条中取 5 个真实 ID 复测全部 404，存活对照 200），且 2025 年 Walden 切换后**不再提供"旧 ID → 新 ID"映射**（[EX-2026-10-14-identity §1](../实验/EX-2026-10-14-身份与去重.md)、[REF-SOURCES §5](../调研/数据源事实.md) 第 10–16 条）。
  5. 标题仍不能当身份：跨来源归一化后 **16% 的记录与别的 DOI 共用同一个标题 key，最大一组 7 篇不同论文**；反方向 **约 1/3 的论文标题在预印本 → 正式版之间会变，其中 11% 无法用归一化救回**（[EX-2026-10-14-identity §3](../实验/EX-2026-10-14-身份与去重.md)）。
- **首领规则（三条，必须实现）**：
  1. 组的首领 = **组内最早见到的那条记录**；`work_key` 永不被改写。
  2. **禁止硬删记录**——删除一律标 `record.status='tombstone'`。否则首领消失会让 `work_key` 失效。
  3. **合并 = 重定向，不是改名**：保留较早的（或已挂 Zotero 的）那个组，另一个写 `work.merged_into` 指向它，并把 `work_member` 改指过去。**拆组**是唯一需要"新键"的操作：拆出部分取它自己最早成员的 `record_uid`；只有当那个成员恰是原首领时才需要例外处理。
- **否决**：OpenAlex `work_id` 作主键（404 无跳转）；标题哈希作 uid（两个方向都会错 + 语义不匹配）；派生式 **work** 键（成员一变键就变）；**随机铸造 `work_uid`**（不可复现，换来的解耦当前用不到）；`canonical_key` 列（有了确定性 `record_uid` 与 `record_ident` 之后它是冗余的——需要展示用的 handle 时**按需从 `record_ident` 派生**，不必存）。
- **代价**：① 所有面向用户的查询要经过分组层 join——**写入变简单，读取变复杂**；② 需要一条"重新分组"维护任务；③ `work_key` 与"首领记录是否存在"耦合，靠首领规则第 2 条兜住；④ `works/<work_key>/` 的目录名是哈希样，可读性由出口（`list` / `open` / `export`）提供（[ADR-0033](ADR-0033.md)）。
