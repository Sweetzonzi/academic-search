# ADR-0022　arXiv HTML 可用性判定

**状态**：accepted（2026-10-14）

**决策**：必须 GET `/html/<id>` 看状态码，不能读 Atom feed 的 `type="text/html"` 字段

**为什么**：该字段对每篇都声明可用，但实测 2004 年论文返回 404；2009 年及以后抽样均可（arXiv 已回溯转换）
