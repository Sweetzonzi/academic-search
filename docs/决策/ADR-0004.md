# ADR-0004　中文摘要写回 Zotero 时用 **child note**，不改 Abstract 字段、不塞 Extra

**状态**：accepted（2026-10-14）

- **理由**：child note 不破坏元数据、可批量识别与回滚、点开即读；`Abstract` 字段会覆盖原文摘要且污染导出；Extra 会被行语法解析并随导出泄漏（[REF-ZOTERO §3](../调研/Zotero能力.md)）。
- **否决**：写入 Abstract；写入 Extra；写成 `.md` 附件（通常不被全文索引，且占附件位）。
- **代价**：条目树笔记变多；若日后开启 Zotero 同步，这些笔记会上传到 zotero.org。
