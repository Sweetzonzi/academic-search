# 术语表

> 全项目唯一的术语定义处；其他文档只链接，不复述。

| 术语 | 含义 |
|---|---|
| **agent skill / SKILL.md** | agent 按需加载的指令包：`<name>/SKILL.md`（YAML frontmatter 必填 `name`、`description`）+ 可选 `references/`、`scripts/`、`assets/` 资源目录 |
| **DSH** | 本机运行的 DeepSeek Harness（本项目的 agent 宿主），提供 skill 装载、schedule 提醒、子 agent 等能力 |
| **MCP** | Model Context Protocol；把工具 schema 常驻注入模型上下文的一种接入方式（本项目不作为主路径） |
| **sidecar** | 挂在主系统旁边、只服务主系统、删掉不影响主系统的配套存储。本文中 = **一个 SQLite 文件** |
| **字节层（`bytes/` + `works/`）** | 派生字节的家，**两个坐标两层**：`bytes/` 按内容寻址存实体，`works/` 按作品组织人读投影。见 [DESIGN §4.3.1](02-设计说明书.md)、[ADR-0033](决策/ADR-0033.md) |
| **`bytes/`（内容坐标）** | 内容寻址的字节存储，路径 `<sha 前2位>/<sha256>`；**全库唯一的字节实体**，相同字节只存一份，**文件设只读**。装全部字节，**不分原始与派生** |
| **`works/`（作品坐标）** | 按 `work_key` 组织的**人读投影**（`paper.md`、`figures/`、`captions.json`）；每个文件是 `bytes/` 里的**硬链接**（不占额外空间），**删掉可完整重建**。路径不得被长期保存（[ADR-0033](决策/ADR-0033.md)） |
| **record（记录）** | **一条来源记录**：某个来源（arXiv / OpenAlex / Crossref / S2 / 出版社）给出的某一篇论文的一份元数据，键为 `(source, source_id)`。同一篇论文来自多个来源 = 多条记录，**各自保留、互不覆盖**。对外 id 为 `record_uid`——由 `(source, source_id)` **确定性派生**（同一记录在任何机器上都是同一个值） |
| **work / work_key** | 一篇"作品"的**分组身份**：把若干条记录归为一篇论文。`work_key` **就是组内最早见到的那条记录的 `record_uid`**，不另铸 id。分组是**可撤销的视图**，不是不可变的真相；因此**全库没有任何随机生成的标识符** |
| **record_ident** | 记录上的标识别名：OpenAlex `W…` / DOI / arXiv ID / PMID / S2 CorpusId。回答"这条网络结果记过没有" |
| **itemKey** | Zotero 条目的稳定标识（`items.key`）；**不用自增 `itemID`**（重装/同步后会变） |
| **具名查询（named query）** | 领域画像里的一条**可重放查询**：名字 + filter + 年份窗 + 可选 `expires`。由 `sync --query <name>` 执行（[ADR-0049](决策/ADR-0049.md)）。见 [ADR-0027](决策/ADR-0027.md) |
| **候选池（candidate）** | 检索结果在进入 Zotero 之前的暂存区：每篇作品一行，含评分、理由与首次入池的 `run_id`（分级列在初版不写，[ADR-0051](决策/ADR-0051.md)）；**没有状态列**（[ADR-0044](决策/ADR-0044.md)） |
| **dismissed（`dismissed_at` / `dismissed_until`）** | 候选池上唯一的表态：非空的 `dismissed_at` = 不要（不再主动推荐，仍可被显式搜索到）；`dismissed_until` 非空 = 到期后允许重新浮现。**初版没有写入入口**（[ADR-0051](决策/ADR-0051.md)） |
| **质量分级（A/B/C）** | 质量闸门的输出，随候选落库；`search` 默认按 `B` 过滤，黑名单无条件排除（[ADR-0044](决策/ADR-0044.md)）。**初版不实现分级**，只有撤稿与黑名单硬排除（[ADR-0051](决策/ADR-0051.md)） |
| **derived_content** | 短派生文本的缓存键与指针：`(content_hash, kind, lang, model_id, prompt_version, terms_version)` + `sha256`；文本本身在 `bytes/`（[ADR-0045](决策/ADR-0045.md)、[ADR-0054](决策/ADR-0054.md)） |
| **artifact** | 记录级溯源：`(record_uid, kind, sha256)`，回答"这份产物来自哪条记录" |
| **dup_suspect** | L2 弱判据的待确认登记：一条记录与一个已有 work 疑似同篇，**只登记、不归组**（[ADR-0048](决策/ADR-0048.md)、[IFACE-DATA §3.9](接口/数据模型.md)） |
| **源适配** | 把各来源的字段翻译成同一套 `record` 列的那一层：字段映射、源能力矩阵、规范枚举、源文本规范化与 work 级聚合规则见 [IFACE-SOURCE](接口/数据源适配.md)（[ADR-0052](决策/ADR-0052.md)） |
| **规范 type** | 跨源统一的文献类型取值（`article` / `preprint` / `chapter` / `thesis` / `paratext` / `other`）；硬排除只认 `paratext`（[IFACE-PAYLOAD](接口/输出载荷.md)） |
| **译名表（terms）** | `config/terms.toml`：中英译名对照，供翻译保持一致；`terms_version` = 文件内容 `sha256` 前 8 位，进派生缓存键。与本文档（项目术语表）无关（[ADR-0054](决策/ADR-0054.md)） |
| **定位器（`read`）** | 不是返回全文，而是返回 `bytes/` 里的 `paper.md` 路径、图件映射与锚点行号索引——路径现场拼、不落库（[ADR-0053](决策/ADR-0053.md)、[IFACE-PAYLOAD](接口/输出载荷.md)） |
| **run 留档** | 一次 run 的三样产物：`data/runs/<run_id>/` 下的 `run.json`、`report.md` 与 `responses/`；`data/latest-report.md` 指向最近一次（[ADR-0055](决策/ADR-0055.md)） |
| **promote** | 把候选写入 Zotero 成为正式条目，并打 provenance 标记 |
| **provenance** | 来源与生成过程的记录：来源、获取时间、原始响应、决策理由、模型与提示词版本 |
| **ft-cache** | Zotero 为每个已索引附件生成的纯文本全文缓存（`storage/<key>/.zotero-ft-cache`） |
| **FTS5** | SQLite 全文检索模块。v1 只用默认 `unicode61` 分词器索引**英文原文**（[ADR-0042](决策/ADR-0042.md)）；中文检索的实测数据见 [SQLite 中文检索](调研/SQLite中文检索.md) |
| **polite pool** | OpenAlex 过去靠 `mailto` 识别的免费高速通道，**已于 2026-02 废除** |
| **OA / TDM** | 开放获取 / 文本与数据挖掘（Crossref `link[]` 中的 `intended-application: text-mining`） |
| **run / run_id** | 一次采集执行及其标识，用于幂等、观测与回滚 |
| **LibraryBackend** | 「我的库」的存储后端接口：`ZoteroBackend` / `FileBackend` / `None`；权威随后端而定（Zotero 只是默认实现） |
| **文本化 / `paper.md`** | 把论文转成 Markdown 供 LLM 阅读的产物；与图件同目录存放 |
| **锚点** | 文本化产物中的定位标记：`<!-- page: N -->`（真实页码）或 `<!-- sec: 3.2 -->`（近似章节锚点），用于结论溯源 |
| **便携 pandoc** | 随工具分发的 pandoc 单文件二进制，用于 LaTeX / HTML → Markdown 转换 |
