# M0：额度与增量实测

> 操作手册。它是 M1 的**省钱前置，不是阻塞**：增量已有「`publication_date` 回看 N 天 + 本地去重」兜底（[PLAN §1](../04-里程碑与计划.md)、[DESIGN §4.7](../02-设计说明书.md)）。

## 1. 申请 OpenAlex 免费 API key

- 入口：openalex.org 账号设置中的 API key（具体页面以官方当前指引为准，本文未逐步核实）。
- 校验：带 key 请求一次 `filter` 查询，确认 `x-ratelimit-limit-usd` 从 `0.1` 提升到约 `1`。

## 2. 增量口径实测

```powershell
# 无 key / 有 key 分别请求，比对额度响应头与是否 403 / 402
curl.exe -i "https://api.openalex.org/works?filter=from_updated_date:2026-10-13&per-page=1"
curl.exe -i "https://api.openalex.org/works?filter=from_created_date:2026-10-13&per-page=1"
```

要回答的是 `Q1`：`from_created_date` / `from_updated_date` 是否真的属付费层。

## 3. 结论记录

产出一份结论记录，**写入 `docs/实验/`**（命名 `EX-YYYYMMDD-额度`）并在[实验注册表](../实验/README.md)追加一行：额度上限、增量口径可用性、被选定的采集路径（`filter` 轮询 / `search=` / 两者混用）。

**不要写 `reports/`**：它在 `data/` 下、不进版本库，结论会随清理消失。
