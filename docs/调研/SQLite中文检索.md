# SQLite / FTS5 中文检索实测

| 查询 | `unicode61`（默认） | `tokenize='trigram'` | `LIKE` |
|---|---|---|---|
| 剩余使用寿命 | 0 命中 | ✅ | ✅ |
| 世界模型 | 0 命中 | ✅ | ✅ |
| 寿命预测 | 0 命中 | ✅ | ✅ |
| 神经网络（4 字） | — | ✅ | ✅ |
| 图神经（3 字） | — | ✅ | ✅ |
| 模型 / 寿命 / 世界（**2 字**） | 0 命中 | ❌ **仍失效** | ✅ |

**结论**：默认分词器对中文完全失效；trigram 可用但只对 **≥3 字**有效，2 字词需 `LIKE '%…%'` 兜底或先分词（如 jieba）再索引。

> **据此定下的设计**：v1 不做中文分词——检索一律用英文，FTS5 只索引英文原文，中文翻译不进索引（[ADR-0042](../决策/ADR-0042.md)）。本节数据保留作为日后要开中文检索时的依据。
