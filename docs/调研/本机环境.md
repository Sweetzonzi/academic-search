# 本机环境事实

> 本机实测快照。换机器、升级依赖或改路径后需重测。

| 项 | 实测值 | 对设计的含义 |
|---|---|---|
| Zotero 版本 | **9.0.4**（`D:\Zotero\zotero.exe`，2026-05-22）；四处印证：注册表 `DisplayVersion`、exe 文件版本、prefs `extensions.lastAppVersion`、settings 表 `client/lastVersion` | 本地 API **只读** → 写入不可用 |
| 数据目录 | `D:\ZoteroLib`（由 profile `prefs.js` 的 `extensions.zotero.dataDir` 指定，`useDataDir=true`） | 路径不能写死，须从 prefs 解析 |
| 数据库 | `zotero.sqlite` 2,326,528 B；`journal_mode=delete`、`user_version=0`、`page_size=4096`、`integrity_check=ok`；**无 `-wal/-shm`**；只读副本 SHA256 与源一致 | 可直接复制为一致快照；读取安全 |
| 本地 API 开关 | `extensions.zotero.httpServer.localAPI.enabled=true`；`httpServer.enabled` 键在 7+ 已废弃 | 开关已开 |
| 本地 API 进程 | 23119 端口未监听；`/api/users/0/items?limit=1`、`/connector/ping` 均"目标计算机积极拒绝" | 任何 API 路线都必须先拉起 Zotero |
| 同步状态 | 所有 items `version=0, synced=0`；`libraries` 仅 `(1,'user',1,0)`；`groups` 0 行；无 API key | **Web API 路线也不通** |
| 库规模 | items 16 行、`deletedItems` 0 → 顶层条目 **5**；itemType：attachment 6、annotation 3、preprint 2、note 2、journalArticle 2、conferencePaper 1；collections **1**（"世界模型"）；tags **3**（CS-AI、CS-LG、Stat-ML）；creators 28；itemAttachments 6（全部 `linkMode=0`、application/pdf） | 定位为"锚"而非"主体" |
| 全文索引 | `fulltextItems` 6 行，`indexedPages` 均等于 `totalPages`；**`indexedChars` 列为 NULL**（不可用于计数）；`fulltextWords` 13,142 词 | 全文检索不需要解析 PDF |
| 全文缓存 | 每个附件目录含 `.zotero-ft-cache`（45 KB–292 KB 纯文本） | 免 PDF 解析的全文通道 |
| 目录一致性 | `storage/` 有 13 个子目录但 `itemAttachments` 只有 6 行 → **7 个孤儿目录**（重复导入残留） | 遍历必须以数据库为准 |
| 孤儿附件 | 1 个 `parentItemID IS NULL` 的独立附件 | 证明 Zotero 允许"有文件无父条目"，同理允许"有条目无文件" |
| 顶层条目附件分布 | 5 个顶层条目**各有 1 个附件**（各 1 条全文索引） | 库里暂无"仅元信息条目"实例，但模型支持 |
| 运行时 | Python 3.12.14（DSH bundled，内置 sqlite **3.53.1**，FTS5 可用）/ anaconda 3.12.7；**无 uv、无 sqlite3 CLI、无 pandoc、无 libreoffice**；`pymupdf` 可用；`requests`/`PyYAML`/`feedparser`/`pyzotero` **缺失** | 核心链路建议仅用标准库 |
| 网络 | OpenAlex 200（约 943 ms）、arXiv 200（约 1190 ms）、Crossref 200（约 1025 ms，另一轮 429）、Semantic Scholar **429** | 主源直连可用，无需代理 |
| 库内论文主题 | 全部为"世界模型"方向：DreamerV2、DreamerV3、I-JEPA、World Models 综述、World Model as a Graph | 领域画像的起点 |
