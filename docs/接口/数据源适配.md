# 数据源适配

> 逐源把「源字段 → `record` 列」翻译成同一套 schema，并定义**源能力矩阵、源文本规范化、work 级聚合、硬排除规则与画像到查询的映射**。表与列见 [数据模型](数据模型.md)，决定见 [ADR-0052](../决策/ADR-0052.md)，机器枚举值见 [IFACE-PAYLOAD](输出载荷.md)，源的事实依据见 [数据源事实](../调研/数据源事实.md) 与 [参考资料-公开API事实](../调研/参考资料-公开API事实.md)。
>
> **状态：草案。** 字段路径中，OpenAlex 与 arXiv 两节有本机实测或官方文档支撑（链接见对应行）；**Crossref 一节已本机实测**（[EX-2026-10-16-crossref-fields](../实验/EX-2026-10-16-复核Crossref字段.md)）。

## 1. 三条总规则

1. **一列一个来源语义**：`record` 是"某来源给出的一份元数据"，列值必须来自该来源自身的字段，不做跨源补全（跨源合成只发生在读取端，见 §5）。
2. **取不到写 NULL，不写占位值**：「该源没有这个字段」与「该字段为空」在库里都是 NULL，但在**刷新**时两者意义不同——见 §7 的覆盖规则。
3. **刷新不得用 NULL 覆盖已有值**：跨源与跨次刷新都是常态（arXiv 记录刷新拿不到引用信号），NULL 只表示"这次没取到"，不表示"值没了"。

## 2. 源能力矩阵

| 列 | OpenAlex | arXiv | Crossref |
|---|---|---|---|
| `published_at` | `publication_date`（正式版日期） | `published`（首次提交） | `issued.date-parts` |
| `updated_at` | `updated_date` | `updated`（最近版本） | `deposited` / `indexed` |
| `title` | `title`（缺则 `display_name`） | `title` | `title[0]`（剥标记） |
| `abstract` | `abstract_inverted_index`（需还原） | `summary`（纯文本） | `abstract`（JATS，需剥标记；常缺） |
| `authors` | `authorships[].author.display_name` | `author/name` | `author[].given` + `family` |
| `venue` | `primary_location.source.display_name`（**只用于展示**；判定走下一行） | 无（`arxiv:journal_ref` 仅作备注） | `container-title[0]`（剥标记） |
| `venue_source_ids` | `locations[].source.id` 的并集 | 无（本地判据靠 §9 的「来源自身的载体」兜） | 无 |
| `type` | `type`（映射见 §4） | 恒为 `preprint` | `type`（映射见 §4） |
| `language` | `language` | 推定 `en` | `language` |
| 引用信号（`cited_by_count` / `fwci` / `counts_by_year` / `citation_normalized_percentile`） | ✅ 唯一写入方 | 不写 | **不写**（`is-referenced-by-count` 口径不同，混写会让读取端「取最大」失去意义） |
| `is_retracted` | ✅ | 不写 | 不写 |
| `oa_status` / `pdf_url` | `open_access.oa_status` / `best_oa_location.pdf_url` | 推定 OA，PDF 可构造 `arxiv.org/pdf/<id>` | 不写（只看 `license` / `link[]` 线索，初版不落列） |
| 标识（`record_ident`） | `ids.doi` / `pmid` / `pmcid` / 自身 `W…`（**无 arXiv 键**） | `arxiv:doi`（作者回填，常缺） | DOI 本身 |

## 3. 逐源映射

### 3.1 OpenAlex

- `source_id` = work id（`W…`，小写归一）。
- 摘要：`abstract_inverted_index` 是 `{token: [pos…]}`，**按位置升序拼回**；它不含停用词，还原出来的是"近似原文"（实测约 1260 字符），这是**既定形态**、不做补齐。
- 作者：按 `authorships` 顺序取 `author.display_name`（保序 JSON 数组）；`raw_author_name` 仅在 display_name 缺失时用。
- venue：`primary_location.source.display_name`；注意它可能本身就是 arXiv 这个 repository（预印本的常见情形）。**判定不用它**：载体集合取 `locations[].source.id` 的并集（`venue_source_ids`），`venue` 只是展示用的主载体名（[ADR-0060](../决策/ADR-0060.md)）。
- 上表未列的 `locations[]`、`referenced_works`、`related_works` 初版**不落列**：`locations[]` 只用于 §8 补桥与取载体 source id，后两者属 M4 图谱。
- 依据：[数据源事实 §1](../调研/数据源事实.md)、[参考资料-公开API事实](../调研/参考资料-公开API事实.md)（字段与计费档）。

### 3.2 arXiv

- `source_id` = Atom `id` 里的 arXiv id，**去掉版本后缀**（`1501.00001v2` → `1501.00001`）；v1/v2 因此是同一条记录，重新抓取只更新（[数据模型 §3.1](数据模型.md)）。大小写不敏感（`math/0601001`）。
- `published` → `published_at`，`updated` → `updated_at`：这两个日期是"领域新论文"时间窗的唯一依据（[DESIGN §4.7](../02-设计说明书.md)）。
- `summary` 直接作摘要；其中的换行与空白按 §6 规范化后再算 `content_hash`。
- 分类（`category@term`）初版**不落列**，只用于查询映射（§9）。
- 依据：[参考资料-公开API事实](../调研/参考资料-公开API事实.md)（Atom 字段实测清单）。

### 3.3 Crossref

- 初版只在 `lookup` 里用它兜 DOI：取 `title`、`author`、`issued`、`container-title`、`type`、`abstract`，其余不取。六个字段的实际形状已实测复核（[EX-2026-10-16-crossref-fields](../实验/EX-2026-10-16-复核Crossref字段.md)）：`title` 与 `container-title` 都是**数组**，`issued.date-parts` 年月日齐全，`author` 可能是**空数组**。
- **`title` 与 `abstract` 都常带 JATS 标记，两者都必须先剥标记再入库。** 实测书章标题里出现 `<scp>` 一类内联标记；`title` 是 `title_key` 的输入，不剥会让同一篇论文在两个源下被判成不同作品。
- 剥标记之后还要**折叠空白**：标记剥除会留下换行与连续填充空格，`container-title` 里也有。
- `abstract` 覆盖率低（实测 15 个响应里 5 个），**不能指望 Crossref 补摘要**。
- `10.48550/arXiv.*` 这类 DOI 在 Crossref 返回 404（arXiv 的 DOI 注册在 DataCite），`lookup` 因此返回 `None`。
- 批量采集不在初版（[ADR-0051](../决策/ADR-0051.md)），因此 `record` 里来自 Crossref 的行只会由 `lookup` 产生。

## 4. 规范 `type` 映射

| 规范值 | OpenAlex | Crossref | arXiv |
|---|---|---|---|
| `article` | article / review / letter | journal-article / proceedings-article | — |
| `preprint` | preprint | posted-content | **全部记录** |
| `chapter` | book-chapter | book-chapter / reference-entry | — |
| `thesis` | dissertation | dissertation | — |
| `paratext` | paratext / editorial / erratum / peer-review / libguides / supplementary-materials | editorial / erratum / peer-review / component | — |
| `other` | 其余（dataset / software / report…） | 其余 | — |

工具不得直接比较源 `type` 字符串；只比较规范值。

**Crossref 的 `type` 不能当硬判据**：实测同一本书的章节既有 `book-chapter` 也有 `other`（[EX-2026-10-16-crossref-fields](../实验/EX-2026-10-16-复核Crossref字段.md) (d)）。上表照旧使用，但不要靠 `type` 反推「这是不是章节」。`reference-entry` / `dissertation` 与 paratext 一族的实测样本尚未采到。

`type` 映射的规范值集合与 `record.type` 的取值域是同一套（[IFACE-DATA §3.1](数据模型.md)）。

## 5. work 级聚合规则

面向用户的入口返回 `work`；同一 work 有多条记录时按下表合成（实现落在一处，示例见 [数据模型 §3.3](数据模型.md)）：

| 字段 | 规则 |
|---|---|
| 展示元数据（title / authors / venue / language） | 取 `role=published` 的记录；没有则取最早见到的记录 |
| 载体集合（venue 判定用） | 各成员 `venue_source_ids` 的**并集**，再加各成员来源自身的载体（arXiv 记录因此带 `S4306400194`）。并集为空即不通过名单（[ADR-0060](../决策/ADR-0060.md)） |
| `published_at` | 列表与**增量窗口**用组内**最早**的主日期（预印本日期优先，符合"新论文"语义）；展示时可用 published 记录的日期 |
| `updated_at` | 取最大 |
| 引用信号（cited_by_count / fwci / counts_by_year / percentile） | 取最大（只有 OpenAlex 记录有值） |
| `is_retracted` | **或运算**：任一记录为真即为真 |
| `oa_status` / `pdf_url` | 取非空，published 记录优先 |
| `type` | 取 published 记录的规范值，否则取最早的 |
| `abstract`（结果条目用） | 多成员不一致时按 [ADR-0058](../决策/ADR-0058.md) 的两级规则取值（版本层级 → 文本保真度）；`lookup` 带全文，`search` 需 `--abstract` 且截断 |
| 标识（DOI / arXiv ID / OpenAlex ID） | 按 `record_ident` 全量列出，供人读与溯源 |
| `source_text`（`digest list` 用） | `title` / `abstract` 类取 `role=published` 的记录、没有则取首领记录；正文类（`summary.*` / `extracted_text`）取 `artifact` 里 `converter_version` 与当前一致的那份。取不到即跳过，**不用空字符串占位**（[ADR-0056](../决策/ADR-0056.md)） |

## 6. 源文本规范化与 `content_hash`

顺序固定，四步都做：

1. **剥标记**：HTML 标签、JATS（`jats:*`）、MathML（`mml:*`）整体剥除，标签内的文本保留；
2. **Unicode 归一化**：NFKC；
3. **连字符与引号统一**：各种连字符（U+2010…U+2015、U+2212）统一为 `-`；弯引号统一为直引号；
4. **空白折叠**：连续空白（含换行、不换行空格 U+00A0）折叠为单个空格，首尾去空白；
5. **大小写**：`abstract` 与 `title` 类按**大小写不敏感**（先 lower 再哈希），正文类（`extracted_text` 等）**保留大小写**。

`content_hash = sha256(规范化后的源文本)`，按 `kind` 各算一次；**哈希的是规范化后的文本，不是原始字节**（否则同一段摘要只因换行不同就重算）。

**三个测试向量**（契约测试必须逐条断言）：

| # | 输入 A | 输入 B | 期望 |
|---|---|---|---|
| V1 | `"<jats:p>Hello   world</jats:p>"` | `"Hello world"` | 同一 hash |
| V2 | `"state‑of‑the‑art method"`（U+2011 连字符） | `"state-of-the-art method"` | 同一 hash |
| V3 | `"Fig. 1 shows…\n\nResults"` | `"Fig. 1 shows… Results"` | 同一 hash（摘要类，大小写与空白均不敏感） |

## 7. 刷新与覆盖规则

- **刷新做什么**：`cited_by_count`、`counts_by_year`、`fwci`、`citation_normalized_percentile`、`is_retracted`（必查，安全信号）、`oa_status`、`pdf_url`、`type` / `venue`（预印本可能已发表）、`updated_at`、`refreshed_at`、`seen_count`、`last_seen_at`。
- **要么整体更新，要么不动**：一次刷新里取不到的列**保持原值**，不写 NULL。
- **引用信号只对 OpenAlex 记录刷新**：其他来源刷新时跳过这些列（见 §2）。
- 刷新不改派生缓存键：缓存键只看源文本与生成参数（[DESIGN §4.3.9](../02-设计说明书.md)）。

## 8. 补桥（L1）

- **时机**：每次 run 收尾，把本次新记录里「有 DOI 或 arXiv ID 但缺对方标识」的集中成一次批量请求（`filter=doi:…|…`，≤100 条/次），失败记入 `counts.failures` 但不阻断主链路。
- **取什么**：`locations[]`（找 submittedVersion 的 arXiv landing page）、`ids`、以及顺带的引用信号。
- **写入**：命中的对面标识补进 `record_ident`（`ns` 按规范枚举），随后由 `group()` 走 L1 归组（[DESIGN §4.2.2](../02-设计说明书.md)）。
- **校验**：补桥结果必须用标题相似度 + 年份 + 首作者交叉校验，冲突时标 `metadata_conflict`、**不归组**；**桥是「声明」不是「标识」**——校验落在 `group.ingest()` 的 L1 分支，且在 `merge_works()` 之前（[ADR-0064](../决策/ADR-0064.md)）。

## 9. 画像 → 查询映射

**结构化条件走 `filter`，主题条件走 `search.title_and_abstract=`**（[ADR-0063](../决策/ADR-0063.md)）。计费按「有没有做全文检索」分档：`filter` 不含全文检索时 `$0.0001`/次，**任何全文检索**（`filter=field.search:` 与 `search.` 参数同价）`$0.001`/次（[EX-2026-10-16-source-contract §1](../实验/EX-2026-10-16-检索口径与来源校验.md)）——所以「避开 `search=`」并不省额度，省额度靠结构化条件与 `spec_hash` 缓存：

| 画像字段 | OpenAlex | arXiv |
|---|---|---|
| `all_of` | 每个值加引号、以 ` AND ` 连接，整体进 `search.title_and_abstract=`；与 `any_of` 组之间也用 ` AND ` | `abs:"a" AND abs:"b"` |
| `any_of` | 每个值加引号、以 ` OR ` 连接 | `(abs:"a" OR abs:"b")` |
| `venues` | `locations.source.id:…`（会名到 S-id 由项目维护的登记表解析，[ADR-0060](../决策/ADR-0060.md)） | **给定白名单时该腿不参与**：arXiv 没有载体概念 |
| `authors` | `raw_author_name.search:…` | `au:"…"` |
| `--min-citations` / `--min-fwci` | `cited_by_count:>N` / `fwci:>X`（叠加不额外计费；两个同时给出取与） | **给了任一条就跳过该腿**：arXiv 没有被引数据（[ADR-0061](../决策/ADR-0061.md)） |
| `since_years` | `from_publication_date:`（结合 [ADR-0055](../决策/ADR-0055.md) 的回看窗口） | 同左，但**按 `published` 判**（arXiv 日期才是提交日期） |
| `expires` | 到期后 `sync` 跳过该查询；被 `--query` 显式点名时照跑并标注"已过期" | 同左 |

**构造与归一化**：`spec_hash` 取**这次会下发的远端请求的声明式参数**的规范化形式（字段排序、大小写归一、关键词排序），收哪些参数只有一条判据——**它改不改变远端请求**（[ADR-0062](../决策/ADR-0062.md)、[ADR-0043](../决策/ADR-0043.md)）。因此 `--limit` / `--abstract` / `--in` **不进** hash，而 `--source`、`--sort`、`--min-citations`、`--min-fwci` 进；显式给的 `from` / `to` 进，**算出来的具体日期不进**（否则窗口每天挪一天、hash 每天变一次）。

**一次远端取数固定取一页 100 条**（OpenAlex `per_page`、arXiv `max_results`），`--limit` 只截断展示。计费按次不按条（实测 `per-page=1` 与 `per-page=100` 同价），所以取少不省钱、只减少入库量；`--sort` 因此不是展示偏好而是取数的另一端，两个档各抓一次、都进同一个池（[ADR-0062](../决策/ADR-0062.md) 决策 5/6）。
