# sidecar 存储与迁移

> 存储的不变量与 schema。**M1 起 DDL 实体迁到 `src/**/schema.sql`**，本文只保留「为什么这些约束必须存在」并链接过去。

## 1. 身份公式（全项目唯一定义处）

```
record_uid = lower(base32(sha256(source ‖ 0x1f ‖ normalize(source_id))))[:20]
work_key   = 组内最早见到的那条记录的 record_uid          # 不另铸 id
```

- `‖` 是字节拼接，`0x1f` 是 US 分隔符——成本为零，避免拼接歧义。
- `normalize(source_id)`：**必须做**。arXiv id 大小写不敏感（`math/0601001`）、DOI 按规范大小写不敏感、OpenAlex `W` id 大小写不敏感；不做归一化，同一篇论文会因大小写产生**两条记录、两个 `work_key`**。
- `[:20]`：截断到 20 字符 × 5 bit = **100 bit**，长度固定。
- 输出**统一小写**：Windows 与 macOS 的路径不区分大小写，而 `record_uid` 会出现在 `works/<work_key>/` 这类路径里；统一小写可避免「看似两个 id、实为一个路径」。
- 哈希在这里只做**格式归一化**（把两个字段压成单列定长），**不做去重**——`(source, source_id)` 本身已经是唯一键。本公式的任何改动都会改变全部 id 与全部 `works/` 路径，属于破坏性变更。

理由与首领规则见 [ADR-0003](../决策/ADR-0003.md)、[ADR-0023](../决策/ADR-0023.md)。

## 2. 两层字节布局的不变量

| 不变量 | 说明 |
|---|---|
| 查询只有一个入口 | sidecar SQLite；`bytes/` 与 `works/` 都不接受查询 |
| 大块字节只有一份实体 | `bytes/<sha 前2位>/<sha256>`，内容寻址，相同字节只存一份 |
| `works/` 是可重建投影 | 其中每个文件是 `bytes/` 里的硬链接；删掉可完整重建 |
| 路径不落库 | 库里只存 `sha256`；`bytes/`、`works/` 下的路径一律现场拼 |
| `works/` 路径不得被长期保存 | 不写进 SKILL.md 硬编码、不写进导出包、不落库 |

命名与坐标见 [ADR-0033](../决策/ADR-0033.md)；硬链接与只读见 [ADR-0034](../决策/ADR-0034.md)。
