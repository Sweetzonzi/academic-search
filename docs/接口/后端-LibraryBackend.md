# 本地库后端契约：`LibraryBackend`

> **状态：框架，待设计。** 下面只固定已经定下的部分；方法签名、错误语义与契约测试清单待补。
>
> **初版（M0–M4）不实现任何后端**：三种实现都顺延到 M5（[ADR-0032](../决策/ADR-0032.md)）。

## 1. 三种实现（[ADR-0009](../决策/ADR-0009.md)）

| 实现 | 存储 | 权威 |
|---|---|---|
| `ZoteroBackend` | sqlite 只读副本 + Zotero 官方 API 写 | Zotero |
| `FileBackend` | 本地 `library/*.md`（YAML front-matter + BibTeX 导出） | `library/` 目录 |
| `None` | 只用语料库 | 无 |

## 2. 已定的边界（[ADR-0008](../决策/ADR-0008.md)、[DESIGN §4.3.2](../02-设计说明书.md)）

- 「我的库」与「领域语料」各自权威，单向 `promote`，没有字段两处可改；
- 同一组契约测试跑两个后端，去重与导出是共同验收项（[07-风险登记册](../07-风险登记册.md)）；
- 去重第一层按后端分别实现，共用同一套 `identifiers` 归一化函数。
