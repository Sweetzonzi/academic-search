# OpenAlex 引用阈值与作者 OR

**实测**：2026-10-21，使用环境变量 `OPENALEX_API_KEY`，7 次真实请求。脚本为 `experiments/implementation-review/00_query_semantics.py`；运行产物为该目录的 `out/query-semantics.json`（不进版本库）。每次取 3 条，只选 ID、引用指标与作者；不打印或保存 key。请求费用响应头合计 `$0.0016`。

## 1. 包含下界

| 过滤条件 | HTTP 状态 | 命中计数 |
|---|---|---|
| `cited_by_count:100` | 200 | 72,962 |
| `cited_by_count:100-` | 200 | 5,394,868 |
| `cited_by_count:>100` | 200 | 5,321,906 |
| `fwci:2.5` | 200 | 2,388 |
| `fwci:2.5-` | 200 | 25,602,723 |
| `fwci:>2.5` | 200 | 25,600,335 |

两组开放区间的计数都等于「严格大于 + 等于」；按相应指标升序取样时，开放区间的 3 条样本分别都落在 `100`、`2.5` 的边界上。这支持用 `N-` 表达包含下界，不能把 `>N` 当成包含等号。计数是该批请求的快照，会随语料变化；实验未覆盖所有数值范围。

## 2. 作者 OR

`raw_author_name.search:"Richard S Sutton" OR "Michael L Littman"` 返回 HTTP 200、396 个匹配。它证明单个作者搜索条件接受带引号姓名短语的 OR 组合；没有比较两个作者全集，也不证明同名消歧或所有返回项的语义准确性。

**官方文档**：[OpenAlex Search](https://help.openalex.org/api/searching/) 的作者署名搜索说明支持这一构造，重复作者搜索条件会取 AND。文档依据与本实验的真实响应分别记录，不将 arXiv 的离线测试当成真网核验。
