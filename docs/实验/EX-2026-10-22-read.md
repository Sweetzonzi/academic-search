# read 的真实双路线、缓存与阅读验收

> 范围：arXiv LaTeX 源码与 HTML。真实转换与网络取件分别列证据；没有验证本地 PDF 解析、扫描件、出版社页面或所有公式的实际渲染。

## 1. 复现入口

脚本：[experiments/m2/27_read_acceptance.py](../../experiments/m2/27_read_acceptance.py)。`--out` 必须是新目录；每条路线使用独立 sidecar、`bytes/` 与 `works/`，不碰日常库。脚本检查首次读取、重复读取、删除投影后的重建、每张图的内容一致性、锚点行号与全量字节哈希。

```powershell
$env:PYTHONIOENCODING='utf-8'
& 'D:\anaconda3\python.exe' experiments\m2\27_read_acceptance.py --out experiments\m2\out\read-live --arxiv 2610.18630
& 'D:\anaconda3\python.exe' experiments\m2\27_read_acceptance.py --out experiments\m2\out\read-snapshot --sample experiments\m1.5\2610.18630v1
```

`--sample` 只用本地已下载的论文快照；HTML 快照没有下载媒体时，离线转换会提示缺图。`--arxiv` 使用真实 arXiv feed 与原件，HTML 路线先下载 HTML，再由 `read` 转换并取媒体。输出 `result.json` 保留路径、哈希、警告和请求数；产物位于被忽略的 `out/`。

**工具实测**：便携 pandoc 3.9、PDF 图渲染器 `pdftocairo@24.03.0`。本次宿主的受限子进程不能启动 pandoc（返回 `3221225794`），经宿主命令授权在沙箱外完成真实工具验收；没有把该退出码误报为论文转换缺陷。

## 2. 真实网络与缓存

论文：[Dynamic Programming for A Linear-Gaussian Dual Control Problem](https://arxiv.org/abs/2610.18630v1)。本次执行留档为 `experiments/m2/out/read-accepted-20261022/result.json`。

| 路线 | 正文字符数 | 章节锚点 | 图件 | 首次 read 请求数 | 重复 read 请求数 | 删除投影后 read 请求数 |
|---|---|---|---|---|---|---|
| LaTeX | 91,028 | 27 | 2 | 1 | 0 | 0 |
| HTML | 149,342 | 53 | 2 | 2 | 0 | 0 |

这里的请求数只计 `read`，不含前置 `lookup`，也不含 HTML 路线预先执行的 `download --source html`。两条路线的图件均可按定位器找到；重建后逐图比对内容一致，`verify` 全量检查均为 0 个不匹配。

LaTeX 正文 sha256 为 `e46326df17c1d4cd6ea76465eb2cde0e5c771891157441f0353c04e869a45140`；HTML 为 `d496baa13e735eada501b35a2896dd13089e16672aee7d8aa3d4549443c129e3`。转换时间写入元信息，因此再次强制转换可能得到不同正文哈希；重复读取命中同一清单时哈希保持一致。

**缺损实测**：HTML 保留了正文与两张图，但仍有 224 条未解析交叉引用，并返回 HTML 公式宏与布局尚未全面验证的提示。这是可读但有缺损的正文，不能据 `ok=true` 宣称完整无损。

**工程缺陷与修复**：

- Windows pandoc 曾无法创建媒体子目录，并在成功退出时忽略媒体复制错误。转换前预置源码媒体，再归一化为图件；成功退出时的 pandoc 警告也进入缓存提示。
- HTML 中第一张图用 SVG `<object>` 表示，pandoc reader 曾将其丢弃。媒体本地化时将其转成 `<img>`；真实 HTML 验收从 1 张图恢复到 2 张，图注随图保留。真实 pandoc 的内联 SVG object 回归覆盖这一机制。

## 3. 阅读闭环与人工核对

按定位器读取 LaTeX 正文第 6 节的数值实验，而不是从摘要推断方法。该次正文第 955 行给出 `121×81` 的信念状态网格、401 个控制输入、双线性插值与 `10^-6` 的停止阈值；回到源码的数值实验段核对这些值一致。

按 `figures[].ref` 找到图 1 的字节路径并用图像工具打开：图件可辨认坐标 `m`、`P`、`J` 与曲面。正文将其解释为最优代价函数 `J*(m,P)`，与图注一致。图件查看和原文方法参数核对完成了“正文定位 → 分段阅读 → 查看图件 → 给出依据”的一次样本验收，不构成论文理论正确性或方法复现的证明。

**需人读**：语义漂移、整体自包含性、公式与图表是否忠于原文、结论是否有足够实测依据，均不能由链接与哈希检查证明。本次人工复核覆盖新增契约、skill 阅读流程及本样本的方法参数和图件；HTML 的公式渲染、全部引用与其它论文仍需扩样验证。

## 4. 自动化覆盖

`tests/test_read.py` 覆盖离线本地转换、缓存命中、原件与转换器变化、多版本图件隔离、未知版本、陈旧提示、HTML 缺媒体、显式刷新失败、投影失败、写锁、请求账本、空正文与 CLI 定位器。真实 pandoc 用例覆盖 LaTeX、嵌套图件、HTML 与 SVG object；网络层的桩测试不当作真实联网证据。

全量离线回归实跑：**472 passed**（22.15 秒，无跳过）。文档校验的断链、悬空引用与缺失脚本均为 0；AGENTS 自检通过，检查器固定样本漏检 / 误报均为 0。自包含性队列的 5 个候选已人工复核：4 个是文档体系对禁用写法的定义，1 个是“当前版本”包含的词汇误报，均不依赖前版或对话。
