# 技能初始化：启动器回归、独立空库与 OpenAlex 验收

**实测**：2026-10-22（Asia/Shanghai），Windows，Python 3.12.7、SQLite 3.45.3。初始化步骤见 [setup.md](../../skills/academic-search/references/setup.md)，启动器契约见 [IFACE-SKILL](../接口/交付物-skill打包.md)。

## 1. 离线回归

`tests/test_launchers.py` 在独立临时目录复制代码与薄 bundle，从无关 cwd 启动子进程；清除继承的仓库根、解释器与 `PYTHONPATH` 配置，以假 key 或无 key 运行。Windows `.cmd` 和 Git Bash 执行的 `.sh` 共 **28 项通过**，包括：

- 安装副本通过 `root.txt` 绑定含空格的仓库路径，诊断成功且不创建数据库；本地命令随后初始化空库，零请求、返回空列表。
- 正确的显式 `--root`（含等号形式）覆盖错误环境变量与坏 `root.txt`；缺少路径参数时非零退出。
- 根错误与 Python 错误的诊断阶段明确，key 只报存在性；`--diagnose` 与子命令混用时拒绝执行。
- 用真实 Python 执行候选探针，模拟旧版本、缺 `sqlite3`、缺 `tomllib` 和静默退出的存根，均能回退；PATH 中不合格的首选也会让位给后续候选，全部失败时给修法。
- 无 key 可做本地查询；只读数据库时诊断仍可完成，本地检索返回 `data_not_writable`。

完整离线测试为 **430 passed、2 skipped**；两项跳过均因本机没有可用的 pandoc，属于转换测试。`.sh` 已在 Git Bash 中运行，未在原生 Linux / macOS 验证。

## 2. 真实来源与权限边界

`experiments/implementation-review/03_initialization_acceptance.py` 创建全新代码副本、安装副本和空库，不复制用户配置或缓存。非联网子进程移除 key，真实 key 只经环境变量传给 OpenAlex 子进程，产物保存前脱敏。

| 执行环境 | 检查结果 |
|---|---|
| 受限沙箱 | 启动器与离线空库自检通过；OpenAlex 返回 `source_error`，原因为套接字 `WinError 10013` |
| 获准联网 | 同一流程三层均通过；OpenAlex `network=true`、1 次请求、`counts.complete=true`，无来源失败或降级 |

OpenAlex 查询为 `search --source openalex --all-of "world model" --refresh true --limit 1`。客户端按计费档估算费用 **`$0.001`**，不是响应头费用实测。本实验未发起真实 arXiv 请求，未主动使用错误 key 或耗尽额度，因此不证明这些分支的真实服务行为。

两次产物分别位于 `experiments/implementation-review/out/initialization-acceptance/20261021T190727138503Z/` 与 `experiments/implementation-review/out/initialization-acceptance/20261021T190740900964Z/`，目录名为 UTC。每次含脱敏 stdout / stderr、`summary.json` 和独立库；不进版本库。

根校验要求显式根含代码后，`experiments/implementation-review/02_warnings_acceptance.py` 的预算快照也复制 `src/`。在用户库的一致性备份副本上执行其默认验收，**7 组通过、0 请求**；没有写用户库。该次产物在 `.pytest_cache/warnings-compatible-root/acceptance-out/`，是临时验收夹具。

## 3. 复现

```powershell
$env:PYTHONIOENCODING='utf-8'
# basetemp 使用新的、专属的临时目录；pytest 会清理该目录。
& 'D:\anaconda3\python.exe' -B -m pytest tests/test_launchers.py -q --basetemp .pytest_cache/launcher-repro
& 'D:\anaconda3\python.exe' -B experiments/implementation-review/03_initialization_acceptance.py
# 已有进程级 key 且获准联网时，增加一次真实来源请求：
& 'D:\anaconda3\python.exe' -B experiments/implementation-review/03_initialization_acceptance.py --live
```

完整离线测试可将上述 pytest 的目标换成 `tests/`；受限执行身份访问默认系统临时目录失败时，使用工作区内独立的 `--basetemp`，不必放宽权限。文档的语义一致性与首次阅读是否顺畅仍需人读，脚本通过不替代该项复核。
