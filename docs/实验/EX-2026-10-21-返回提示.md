# warnings 的真实启动器与 OpenAlex 验收

**实测**：2026-10-21。通过 `skills/academic-search/scripts/run.cmd` 启动独立 CLI 进程，读取仓库真实本地库；最终验收的 9 组调用全部通过。OpenAlex 实际发起 1 次请求，按客户端计费档估算 `$0.001`，不是响应头费用实测。字段定义见 [IFACE-PAYLOAD §2](../接口/输出载荷.md)。

## 1. 实跑结果

| 调用场景 | 网络请求数 | 提示与验收结果 |
|---|---|---|
| 离线全库清单 | 0 | 返回 20 篇，无 `warnings` 字段 |
| 仅引用排序，离线 | 0 | 返回 20 篇，无来源跳过提示 |
| 仅选 arXiv，引用数下限 100，要求刷新 | 0 | 返回 7 篇本地已有、具有聚合引用指标的 work；一条提示说明 arXiv 不提供被引次数，已跳过其采集 |
| 仅选 arXiv，FWCI 下限 2，要求刷新 | 0 | 返回 4 篇本地已有匹配；一条提示说明 FWCI 能力限制 |
| 仅选 arXiv，两个引用阈值与 ICRA 白名单，要求刷新 | 0 | 返回空列表；三个限制合并为一条来源跳过提示 |
| 本地已命中的标题查询，要求刷新 | 0 | 返回 1 篇；提示与 `degraded.reason` 一致，说明标题查询只查本地 |
| 真实库备份，候选预算 1，偏移 1 | 0 | 空页且 `truncated=true`；仍提示预算耗尽、可能有未检查的匹配 |
| `multi-agent decision`，引用下限 100，引用排序，要求刷新 | 1 | OpenAlex 取回 13 条，arXiv 未请求；一条来源跳过提示，`complete=true`；展示 3 篇，被引数为 410、243、187 |
| 紧接上条的同条件 `auto` 查询 | 0 | 复用新鲜度，返回 3 篇，无 `warnings`；既有 `degraded` 继续说明正常缓存复用 |

引用阈值跳过的是 arXiv 的远端采集；本地具有 OpenAlex 聚合指标的跨源 work 仍可返回。测试调用按顺序执行，记录数仅描述该次本地状态，不提供跨命令快照。预算用例使用 SQLite 一致性备份，在独立验收根写入预算配置，没有改动用户配置。

## 2. 复现与边界

脚本为 `experiments/implementation-review/02_warnings_acceptance.py`，只用标准库；默认执行 7 组零请求验收，`--live` 增加真实 OpenAlex 请求与随后新鲜度复用检查：

```powershell
$env:PYTHONIOENCODING='utf-8'
& 'D:\anaconda3\python.exe' experiments/implementation-review/02_warnings_acceptance.py --live
```

真网验收需要环境变量 `OPENALEX_API_KEY` 与网络权限；受限沙箱的套接字访问返回 `WinError 10013`，获准联网后完成。真实 key 仅传入真网子进程，其他调用使用占位 key；产物保存前对真实 key 脱敏。信封与汇总保存在该目录的 `out/warnings-acceptance/`，不进版本库。另已直接通过启动器查看 `search --help`，三个参数均展示来源能力、阈值和空值处理说明。

**离线验证**：`tests/test_cli.py`、`tests/test_sync.py` 覆盖来源能力跳过、正常离线、新鲜度复用、未选择 arXiv、仅排序、零阈值、组合提示、截断空页、部分来源失败、额度在采集前与中途停止、标题刷新受限，以及已有缓存的 `lookup` 刷新失败；`sync` stdout、`run.json` 与账本结构保持兼容。完整测试为 402 passed、2 skipped。部分来源失败与额度停止使用注入客户端验证，本实验未主动制造真实来源故障或耗尽真实额度。
