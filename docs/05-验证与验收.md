# 验证与验收

> **判据的家是 [REQ §5](01-需求说明.md)**：本文只写「怎么验」与状态，不重抄判据原文；[PLAN](04-里程碑与计划.md) 的每个里程碑在自己的验收列里引用它关闭哪几条。

## 1. 判据 → 验证方法映射

| 判据（[REQ §5](01-需求说明.md)） | 验证方式 | 状态 |
|---|---|---|
| 零重复候选 | 同一检索式连跑两次（`search --refresh true` ×2），比对候选集 | ☐ |
| 零重复写入 | 已入池 work 再次命中时，比对 `record` / `candidate` 的行数与 `run_id` | ☐ |
| 无 PDF 也给摘要 | 取一条无附件的候选走 `digest list → put`，确认中文摘要落 `bytes/` | ☐ |
| 撤稿 / 黑名单不返回 | 构造 `is_retracted=true` 与黑名单 venue 各一条，确认任何档位都不出现 | ☐ |
| 原件取件与缓存 | 同一 work 连跑两次 `download --refresh auto`：第二次 `network=false`、`artifacts[].status=reused`、账本不新增请求；`bytes/` 实体与 `works/<proj>/source.*` 同 inode（[EX-2026-10-18-download](实验/EX-2026-10-18-download.md)） | ☑ |
| 投影可重建（原件） | 删掉 `works/<proj>/` 后重跑 `download --refresh false`：投影按 `bytes/` 重建、零请求（[ADR-0067](决策/ADR-0067.md)） | ☑ |
| 投影目录名可读 | `download` 之后 `works/<proj>` 的名字是 `<4位年>-<首作者>-<标题>-<work_key>`，尾段 20 位反解出 `work_key`；改掉 `record.title` 再跑一次 `download`：旧目录消失、新目录出现、投影仍是硬链接；`merged_into` 的空壳目录被清掉（[ADR-0068](决策/ADR-0068.md)） | ☑ |
| 字节唯一 + `works/` 可重建 | 内容寻址与幂等登记有离线覆盖；真实双路线缓存与重建见 [EX-2026-10-22-read](实验/EX-2026-10-22-read.md) | ☑ |
| `read` 定位器 | 返回同一清单的正文与图件，章节行号现场核验；投影删除后离线重建，无正文与原件且不联网时才报 `projection_missing`（[EX-2026-10-22-read](实验/EX-2026-10-22-read.md)） | ☑ |
| `content_hash` 规范化 | 跑 [IFACE-SOURCE §6](接口/数据源适配.md) 的 V1–V3 三个测试向量，两两必须同 hash | ☐ |
| 写锁与 `busy` | 并发起两个写命令，第二个以 `error.code=busy`、退出码 1 结束（[ADR-0055](决策/ADR-0055.md)） | ☐ |
| 部分失败不影响退出码 | 关掉一个源（`sources.toml`）跑 `sync`，确认 `ok=true`、退出码 0、`counts.failures[]` 列出该源（[ADR-0056](决策/ADR-0056.md)） | ☐ |
| 缓存键由 CLI 现算 | `digest put` 提交一条不带 hash 的项，确认落库键等于按当前源文本重算的值；再对不存在的 `work_key` 提交一次，确认 `skipped[].reason=not_found` 且不写库（[ADR-0056](决策/ADR-0056.md)） | ☐ |
| 入库可撤销 | 顺延到 M5（[ADR-0032](决策/ADR-0032.md)） | ☐ |
| 删 sidecar 可重建 | 顺延到 M5；重建流程见 [IFACE-STORE §4](接口/存储与迁移.md) | ☐ |
| 无头 + 结构化报告 | 由调度器（或等价的无人值守调用）跑一次 `sync`，检查 `data/runs/<run_id>/run.json` 与 `report.md`（以及 `data/latest-report.md`） | ☐ |
| 阅读辅助闭环（锚点 + 图件） | 真实论文分段阅读、方法参数核对与图件查看见 [EX-2026-10-22-read §3](实验/EX-2026-10-22-read.md)；摘要、表格与附录引用的扩样见 [EX-2026-10-22-read-fidelity](实验/EX-2026-10-22-read-fidelity.md)，不证明所有论文转换无损 | ☑ |
| 无需 Zotero 闭环（检索 → 阅读） | 初版天然成立（不接 Zotero）；"→ 导出"随 `export` 顺延（[ADR-0051](决策/ADR-0051.md)） | ☐ |

**量化目标**（观测，不是闸门）的原文见 [REQ §5](01-需求说明.md)：花费与是否联网进返回信封；缓存命中率与本地检索延迟在 M2 之后抽样记录。

## 2. 测试分层

- **单元**：身份派生（`record_uid` / `work_key`）、去重判据 L0/L1、缓存键（`content_hash`）——M1 起；
- **契约测试**：JSON 信封、退出码、`SCHEMA_VERSION` 只增不删——M1 建脚手架（[IFACE](03-接口契约.md)）；fixture 用 `tests/fixtures/` 里**脱敏后的真实响应**（来源：`experiments/m1.5/_cache/`），**不联网**；
- **缓存键**：`content_hash` 的 3 个测试向量（[IFACE-SOURCE §6](接口/数据源适配.md)）——M2；
- **重建回归**：删 `works/` 重投影、删 sidecar 重抓（[IFACE-STORE §4](接口/存储与迁移.md)）——M2；
- **live 测试**：OpenAlex / arXiv / Crossref 的真实请求，按额度人工触发，不进 CI——M1 起；
- **文档校验**：`tools/doc_check.py` / `selfcheck.py` / `test_doc_check.py`（[AGENTS.md](../AGENTS.md) 第 4 节）——改文档即跑。
