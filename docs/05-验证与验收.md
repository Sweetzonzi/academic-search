# 验证与验收

> **判据的家是 [REQ §5](01-需求说明.md)**：本文只写「怎么验」与状态，不重抄判据原文；[PLAN](04-里程碑与计划.md) 的每个里程碑在自己的验收列里引用它关闭哪几条。

## 1. 判据 → 验证方法映射

| 判据（[REQ §5](01-需求说明.md)） | 验证方式 | 状态 |
|---|---|---|
| 零重复候选 | 同一检索式连跑两次（`search --refresh true` ×2），比对候选集 | ☐ |
| 零重复写入 | 已入池 work 再次命中时，比对 `record` / `candidate` 的行数与 `run_id` | ☐ |
| 无 PDF 也给摘要 | 取一条无附件的候选走 `digest list → put`，确认中文摘要落 `bytes/` | ☐ |
| 撤稿 / 黑名单不返回 | 构造 `is_retracted=true` 与黑名单 venue 各一条，确认任何档位都不出现 | ☐ |
| 字节唯一 + `works/` 可重建 | 同内容二次写入比对 `bytes/` 文件数；删 `works/` 后重投影比对（[IFACE-STORE §4](接口/存储与迁移.md)） | ☐ |
| 入库可撤销 | 顺延到 M5（[ADR-0032](决策/ADR-0032.md)） | ☐ |
| 删 sidecar 可重建 | 顺延到 M5；重建流程见 [IFACE-STORE §4](接口/存储与迁移.md) | ☐ |
| 无头 + 结构化报告 | 由调度器（或等价的无人值守调用）跑一次 `sync`，检查 `run.json` 与 `reports/<date>.md` | ☐ |
| 阅读辅助闭环（锚点 + 图件） | 已由 [EX-2026-10-14-textify](实验/EX-2026-10-14-文本化.md) 部分覆盖；端到端在 M3 自测 | ◐ |
| 无需 Zotero 闭环（检索 → 阅读） | 初版天然成立（不接 Zotero）；"→ 导出"随 `export` 顺延（[ADR-0051](决策/ADR-0051.md)） | ☐ |

**量化目标**（观测，不是闸门）的原文见 [REQ §5](01-需求说明.md)：花费与是否联网进返回信封；缓存命中率与本地检索延迟在 M2 之后抽样记录。

## 2. 测试分层

- **单元**：身份派生（`record_uid` / `work_key`）、去重判据 L0/L1、缓存键（`content_hash`）——M1 起；
- **契约测试**：JSON 信封、退出码、`SCHEMA_VERSION` 只增不删——M1 建脚手架（[IFACE](03-接口契约.md)）；
- **重建回归**：删 `works/` 重投影、删 sidecar 重抓（[IFACE-STORE §4](接口/存储与迁移.md)）——M2；
- **live 测试**：OpenAlex / arXiv / Crossref 的真实请求，按额度人工触发，不进 CI——M1 起；
- **文档校验**：`tools/doc_check.py` / `selfcheck.py` / `test_doc_check.py`（[AGENTS.md](../AGENTS.md) 第 4 节）——改文档即跑。
