# 风险登记册

> 活文档：风险状态变化时就地更新。设计决策见 `决策/`，未决事项见 [06-待决事项](06-待决事项.md)。

| # | 风险 | 概率 | 缓解 | 触发信号 |
|---|---|---|---|---|
| R1 | **便携 pandoc 在目标机器上不可用**（缺依赖、被杀软拦截、许可变化） | 低 | 单文件随包放在 `tools/`；pandoc 版本进缓存键（[ADR-0016](决策/ADR-0016.md)）；失败时 `textify` 报错并保留原始字节 | 首次在非本机跑 `textify` 失败 |
| R2 | **`bytes/` 与 `works/` 不同卷，或文件系统不支持硬链接** → 投影建不起来 | 中 | 启动时校验同卷与硬链接支持；不支持则降级为副本并告警（[IFACE-STORE §4](接口/存储与迁移.md)），代价是磁盘占用翻倍 | 启动告警「硬链接不可用」 |
| R3 | **Windows 只读文件删除失败**（`bytes/` 设只读，GC 与重建都要先解只读） | 中 | 清理与重建流程显式解只读；删除失败不吞异常（[ADR-0034](决策/ADR-0034.md)） | 清理或重建报权限错误 |
| R5 | **数据在仓库内，被误清**（重新 clone、`git clean -xdf`、误删目录） | 中 | 备份纪律写进 README、[使用/配置](使用/配置.md) 与[快速开始](使用/快速开始.md) 三处；`config/` 是唯一不可重建的数据，备份 = 复制 `config/`（[ADR-0055](决策/ADR-0055.md)） | 用户报告「画像没了」，或 `config/profile.toml` 消失 |
| R4 | **OpenAlex 额度耗尽**（无 key 每日 $0.10，异常批量抓取一天烧完） | 中 | 检索返回实际花费；读到 `x-ratelimit-remaining-usd` 低于阈值即降级为只查本地并标注（[ADR-0051](决策/ADR-0051.md)） | `cost` 接近上限，或出现 429 / 402 |
