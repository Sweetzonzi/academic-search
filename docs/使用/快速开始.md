# 快速开始

目标：安装并绑定 skill → 验证环境 → 开始检索；只有长期具名查询需要画像。

> **状态：安装与排障可照做，画像和日常示例按 M3 补齐**（[PLAN §1](../04-里程碑与计划.md)）。初版不实现 `export`，「把结果交接给同学」那一步要等它落地（[ADR-0051](../决策/ADR-0051.md)）。

## 1. 安装

1. 按[初始化参考 §1](../../skills/academic-search/references/setup.md#1-安装与路径绑定)保留完整仓库并安装薄 bundle；宿主扫描位置见 [IFACE-SKILL](../接口/交付物-skill打包.md)。已有配置与数据先按第 4 节备份。
2. 按[初始化参考 §2–§3](../../skills/academic-search/references/setup.md#2-python-与调用环境)配置解释器与凭据；示例把环境设置和调用放在同一次执行中，不依赖历史会话。本地与 arXiv 查询无需 OpenAlex key。
3. 按[分层自检](../../skills/academic-search/references/setup.md#4-分层自检)验证启动器、本地库和所需来源的联网能力。一次性检索可直接开始；需要具名查询时再创建画像并运行 `profile check`。
4. **更新安装副本**：改了 `skills/academic-search/` 之后跑 `tools/install_skill.py`（先加 `--check` 只比差异，一致时退出 0）。它只同步 `SKILL.md`、`references/`、`scripts/`，保留本机 `root.txt`，并把被替换的副本备份到 `skills.backup/`。

## 2. 配置画像

- 让 agent 起草 `config/profile.toml` → `profile check` → 把解析结果回显确认（[配置目录](配置.md) §5）。

## 3. 日常用法

- 现在可用：`search`（当场检索，示例见 `skills/academic-search/references/cli-reference.md` 第 1–2 节）、`lookup`（按 DOI / arXiv ID / 标题取一篇）与 `download`（把某篇的原件取到本地，见下面那条）；只看本地库用 `--refresh false`，**不给检索式就把本地库现有条目列出来**（条数受 `--limit` 限制，默认 20）。
- **分批看本地结果**：`search --refresh false --offset 20 --limit 20` 跳过前 20 个 work，展示第 21–40 个；同样适用于带检索词的查询。它只切分本地结果，数据库变化可能改变页边界，远端取数仍是一批。规则见 [ADR-0073](../决策/ADR-0073.md)。
- **下载某篇原件**：先 `lookup` 拿到 `work_key`，再 `download --work <work_key> --refresh auto`——LaTeX 源码优先、没有就回退 arXiv HTML，落到 `works/<proj>/source.*`（`<proj>` = `<年>-<首作者>-<标题>-<work_key>`，尾段才是身份；同一份字节只存一份，第二次同参数调用零请求）。只要 PDF 就加 `--source pdf`（只下载、不解析）。
- **精读某篇论文**：取得 `work_key` 后调用 `read --work <work_key> --refresh auto`，获取转换后的 Markdown 定位器；人和 agent 均优先读 `doc.work_path` 及同目录图件，按章节分段读取。无需先下载或自行阅读原始 PDF、HTML、源码。步骤见 [论文精读流程](../../skills/academic-search/SKILL.md#4-论文精读)，缓存、离线与更新规则见 [CLI 参考 §11](../../skills/academic-search/references/cli-reference.md#11-read)。
- `digest`（翻译与摘要回填）尚未接线（[PLAN §3](../04-里程碑与计划.md)）；`sync` 已接线，示例见 `skills/academic-search/references/cli-reference.md` 第 4 节。

## 4. 备份与迁移

- **先备份 `config/`**：数据在仓库内，重新 clone 或 `git clean -xdf` 会丢 `profile.toml`（[ADR-0055](../决策/ADR-0055.md)）；迁移 = 把 `config/` 复制到新 clone。

## 5. 排障

- 启动、凭据、写权限、沙箱网络与额度问题统一按[初始化参考 §5](../../skills/academic-search/references/setup.md#5-按失败阶段恢复)处理；额度不足时结合 `network`、`cost` 和失败信息说明已完成的来源与剩余缺口。
- `no_profile` → 仅长期具名查询需要第 2 节的画像；一次性检索直接用 `search`。
- 返回条数比预期少 → 看 `counts.local`：`truncated=true` 是候选预算用尽，`venue_filtered_out` 是被 venue 白名单滤掉（[ADR-0070](../决策/ADR-0070.md)）。
