# 快速开始

目标：三步可用（放入 skill 目录 → 生成领域画像 → 试跑一次检索）。

> **状态：框架，由 M3 的交付物子项补齐**（[PLAN §1](../04-里程碑与计划.md)）。下面是五节提纲，每节在 M3 填成可照做的步骤。初版不实现 `export`，「把结果交接给同学」那一步要等它落地（[ADR-0051](../决策/ADR-0051.md)）。

## 1. 安装

- clone 仓库；把 `skills/academic-search/` 复制到各宿主的 skill 目录（[IFACE-SKILL](../接口/交付物-skill打包.md)）；首次运行给出仓库根（`--root` 或 `root.txt`）。

## 2. 配置画像

- 让 agent 起草 `config/profile.toml` → `profile check` → 把解析结果回显确认（[配置目录](配置.md) §5）。

## 3. 日常用法

- `search`（当场检索）/ `sync`（定时增量 + 报告）/ `read`（拿定位与锚点）/ `digest`（翻译与摘要回填）四条最小示例。

## 4. 备份与迁移

- **先备份 `config/`**：数据在仓库内，重新 clone 或 `git clean -xdf` 会丢 `profile.toml`（[ADR-0055](../决策/ADR-0055.md)）；迁移 = 把 `config/` 复制到新 clone。

## 5. 排障

- 额度不足 → 自动降级为只查本地（输出里带 `degraded`）；`busy` → 另一个 run 在跑，稍后重试一次；`projection_missing` → 跑 `textify --work <key>`；`no_profile` → 回到第 2 节。
