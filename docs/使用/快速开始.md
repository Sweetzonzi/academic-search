# 快速开始

目标：三步可用（放入 skill 目录 → 生成领域画像 → 试跑一次检索）。

> **状态：框架，由 M3 的交付物子项补齐**（[PLAN §1](../04-里程碑与计划.md)）。§1 安装已可照做，§2–§5 仍是提纲。初版不实现 `export`，「把结果交接给同学」那一步要等它落地（[ADR-0051](../决策/ADR-0051.md)）。

## 1. 安装

1. clone 仓库，放在一个不会被 `git clean -xdf` 清掉的位置；**先看第 4 节的备份提醒**。
2. 把 `skills/academic-search/` 复制到各宿主的 skill 目录（扫描根与装载建议见 [IFACE-SKILL](../接口/交付物-skill打包.md)）。装到 `~/.dsh/skills/` 之后，定时任务在别的 cwd 醒来也能用。
3. 让 launcher 找到仓库：bundle 直接装在仓库内时不用做任何事；装到别处时，在 `bundle/root.txt` 写一行仓库绝对路径，或设环境变量 `ACADEMIC_SEARCH_ROOT`（`--root` 参数优先级最高）。
4. 指定解释器：设 `ACADEMIC_SEARCH_PYTHON` 指向真正的 Python（Windows 上裸 `python` 常命中应用商店存根，launcher 会探测并给出提示）。
5. 自检：`skills/academic-search/scripts/run.cmd version` 应回 `{"ok": true, ...}` 且退出码 0（POSIX 用 `run.sh`）；再跑 `profile check` 校验画像。

## 2. 配置画像

- 让 agent 起草 `config/profile.toml` → `profile check` → 把解析结果回显确认（[配置目录](配置.md) §5）。

## 3. 日常用法

- 现在可用：`search`（当场检索，示例见 `skills/academic-search/references/cli-reference.md` 第 1–2 节）、`lookup`（按 DOI / arXiv ID / 标题取一篇）与 `download`（把某篇的原件取到本地，见下面那条）；只看本地库用 `--refresh false`，**不给检索式就把本地库现有条目列出来**（条数受 `--limit` 限制，默认 20）。
- **要某篇的原文**：先 `lookup` 拿到 `work_key`，再 `download --work <work_key> --refresh auto`——LaTeX 源码优先、没有就回退 arXiv HTML，落到 `works/<proj>/source.*`（`<proj>` = `<年>-<首作者>-<标题>-<work_key>`，尾段才是身份；同一份字节只存一份，第二次同参数调用零请求）。只要 PDF 就加 `--source pdf`（只下载、不解析）。
- `sync`（定时增量 + 报告）/ `read`（拿定位与锚点）/ `digest`（翻译与摘要回填）尚未接线，示例待实现后补（[PLAN §3](../04-里程碑与计划.md)）。

## 4. 备份与迁移

- **先备份 `config/`**：数据在仓库内，重新 clone 或 `git clean -xdf` 会丢 `profile.toml`（[ADR-0055](../决策/ADR-0055.md)）；迁移 = 把 `config/` 复制到新 clone。

## 5. 排障

- 额度不足 → 自动降级为只查本地（输出里带 `degraded`）；`busy` → 另一个 run 在跑，稍后重试一次；`projection_missing` → 去掉 `--refresh false` 重跑 `read --work <key>`；`no_profile` → 回到第 2 节。
