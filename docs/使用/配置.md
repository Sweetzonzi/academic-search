# 配置目录

所有可配置内容集中在 `config/`，**一份配置一个 TOML、文件名固定**（[ADR-0040](../决策/ADR-0040.md)）。CLI 只读它认识的那几个文件名，**目录里的其它文件一律忽略**——复制、改名、留多份备份都不影响工具行为。

> **备份提醒**：`config/` 里是**唯一不可重建的用户数据**——sidecar 删了能重建，配置删了就没了。

| 文件 | 内容 |
|---|---|
| `config/profile.toml` | 领域画像（**只有一份**） |
| `config/sources.toml` | 启用的检索数据库与开关 |
| `config/search.toml` | 检索行为：刷新阈值 `refresh.max_age_hours`（默认 24）、增量回看 `sync.lookback_days`（默认 30）、余额降级阈值 `quota.min_remaining_usd`（默认 `0.05`；余额低于它即停止联网，[ADR-0066](../决策/ADR-0066.md)）、本地候选预算 `local.max_candidates`（默认 `5000` 条记录，`0` 或负数 = 不限；预算用尽时 `counts.local.truncated=true`，[ADR-0070](../决策/ADR-0070.md)）、质量下限 `quality.min_grade`（默认 B，**初版不生效**：分级顺延，[ADR-0051](../决策/ADR-0051.md)）、载体黑名单 `quality.venue_blacklist`、摘要截断 `abstract.chars`（默认 800；`search --abstract` 打开时生效，见 [IFACE §1](../03-接口契约.md)、[ADR-0059](../决策/ADR-0059.md)）、对外联系邮箱 `contact.mailto`（默认空；填了才进 Crossref 的 polite 通道） |
| `config/terms.toml` | 译名表：中英对照，供翻译保持一致；改一次自动换版（[ADR-0054](../决策/ADR-0054.md)） |

**密钥不进配置文件**：API key 走环境变量（如 `OPENALEX_API_KEY`），因此 `config/` 可以安全地备份与转发。**也不进留档**：`data/runs/` 里的 `responses[].url` 把查询串中的凭据记作 `REDACTED`（[IFACE-PAYLOAD §3](../接口/输出载荷.md)），所以 `data/` 同样没有凭据。

变量名本身就是失败点：宿主起子进程时可能按变量名过滤 `KEY` / `PASSWORD` / `SECRET` / `TOKEN`，已配置的 key 于是在 CLI 子进程里看起来“不存在”。`--diagnose` 的 `openalex_key` 与 `openalex_key_user_scope` 两行用来区分这两种情况，处置见[初始化参考 §3](../../skills/academic-search/references/setup.md#3-openalex-凭据)。

## 1. 领域画像

各人研究方向独立。画像是一组**具名查询**（[ADR-0027](../决策/ADR-0027.md)）：一个方向就是一条查询，同一人关注多个方向就是同一份画像里的多条查询。**agent 写、CLI 只读校验**（[ADR-0039](../决策/ADR-0039.md)）。

> **一次性的查询不用写进这里**：`search --any-of "..."` 可以当场给检索式，结果照样落候选池、照样走缓存（[ADR-0041](../决策/ADR-0041.md)）。**画像里的具名查询由 `sync` 执行**（[ADR-0049](../决策/ADR-0049.md)）；想让某个临时检索变成定期任务，再把它写成一条 `[[query]]`。

### 示例

```toml
# config/profile.toml

[[query]]
name        = "world-model-uav"                        # 也是 sync --query 的名字
all_of      = ["world model"]                          # 交集：两个概念都要在
any_of      = ["UAV", "drone", "aerial", "unmanned"]   # 并集：同一概念的不同写法
venues      = ["ICRA", "IROS", "RA-L"]                 # 可选：venue 白名单
since_years = 3

[[query]]
name        = "multi-agent-decision"
any_of      = ["multi-agent", "multiagent", "MARL", "decentralized decision"]
since_years = 3

# 临时专题：带 expires，到期后不再采集
[[query]]
name    = "world-model-survey"
any_of  = ["world model", "latent dynamics"]
expires = "2026-12-31"
```

### 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 查询名，**本文件内唯一**；也是 `sync --query` 的名字 |
| `any_of` | 与 `all_of` 至少给一组 | 关键词并集，同义词放这里 |
| `all_of` | 同上 | 关键词交集；与 `any_of` 同时生效 |
| `venues` | 可选 | 载体白名单。写**会名**（如 `ICRA`），名字由项目维护的登记表解析成 OpenAlex source id（`src/academic_search/venues.toml`）；**解析不到就报错**，不静默失效。要筛一个没登记过的载体，要么登记它，要么直写 `S…` 的 source id（[ADR-0060](../决策/ADR-0060.md)） |
| `authors` | 可选 | 作者白名单，匹配任一作者（[ADR-0072](../决策/ADR-0072.md)） |
| `since_years` | 可选 | 回看窗口，默认 3 年 |
| `expires` | 可选 | 到期日期；只有临时专题才写 |

**没有 `schedule` 字段**——调度不进工具（[ADR-0038](../决策/ADR-0038.md)）。

## 2. 数据源

```toml
# config/sources.toml

[openalex]
enabled = true

[arxiv]
enabled = true

[crossref]
enabled = true

[semantic_scholar]
enabled = false      # 本机实测：免费共享池第一发即 429
```

**初版来源矩阵**：OpenAlex + arXiv 是采集源；Crossref 只在 `lookup` 里兜 DOI；出版社 HTML 与 PDF 回退不在初版（[ADR-0051](../决策/ADR-0051.md)）。

## 3. 检索的新鲜度

`--refresh auto`（默认）会在「同一检索式上次联网距今超过 `refresh.max_age_hours`」时刷新，否则**跳过并在输出里标注**。判据按**每个检索式的 `spec_hash` 各记各的时间**，不是一个全局时间——否则定时任务与临时检索会互相干扰（定时任务刚跑过 A、你临时查了 B，全局时间就被 B 刷新，该跑的 C 反而被判成「刚同步过」）。**检索式不等价一律刷新**，宁可多花一次不可漏。默认 **24 小时**的依据：arXiv 每天更新一次，同一天刷两次几乎没有额外收益。判据是**每个检索式各记各的时间**，不是一个全局时间——否则定时任务与临时检索会互相干扰。

**这个窗口管 `search` 与 `sync`。** `sync` 按每条查询各自的 `spec_hash` 判，同一条查询在窗口内重跑会跳过并标注（[ADR-0066](../决策/ADR-0066.md) 决策 7）。`lookup` 按标识取，它的 `auto` 判据是「本地有没有命中」，不看时间——所以本节这项配置对同一篇的重复 `lookup` 没有影响。要更新某篇的引用数与撤稿标记，显式给 `--refresh true`（[ADR-0065](../决策/ADR-0065.md)）。

新鲜度与首次回溯完成均要求账本满足[完整采集判据](../接口/输出载荷.md)；首次回溯的查询身份见 IFACE-PAYLOAD §3。离线、部分失败或因额度中断的运行不消耗首次 `since_years` 窗口，也不单独使检索式变新鲜。

```toml
# config/search.toml
[refresh]
max_age_hours = 24

[sync]
# 每次 sync 回看多少天（首次执行改用该查询自己的 since_years）
lookback_days = 30

[quota]
# search / sync 的剩余额度低于它时，停止后续请求，按实际进度标注整次跳过或部分完成。
# 默认 0.05 美元 ≈ 50 次检索（ADR-0066）。
min_remaining_usd = 0.05

[quality]
# 初版不含 A/B/C 分级（ADR-0051）：本节保留为契约，min_grade 在初版不生效。
# 黑名单与撤稿无条件排除，不受此阈值影响。
min_grade = "B"
# 掠夺性载体黑名单：**无条件排除**，初版唯一的跨源质量规则（ADR-0052）。
# 判据与 venues 白名单完全同源（ADR-0060）：作品的载体 source id 集合 ∩ 名单 ≠ ∅；
# 集合为空即不通过。名字同样由 src/academic_search/venues.toml 解析，解析不到就报错，
# 所以要拉黑一个没登记过的载体，得先登记它、或直写 S… 的 source id。
# 文件缺失或留空 = 空列表。
venue_blacklist = []

[abstract]
# `search --abstract` 打开时每条摘要截断到多少字符；`lookup` 固定带完整摘要，不受这项影响。
# 0 或负数 = 不截断。
chars = 800

[contact]
# Crossref 的 polite 通道要一个真实联系邮箱（URL 与 User-Agent 都会带上它）。
# 默认空 = 不带 mailto、按 Public 档限流（5 req/s、并发 1；Polite 是 10 req/s、并发 3）。
# OpenAlex 侧的 polite pool 已于 2026-02 废除、mailto 被忽略，那边靠 OPENALEX_API_KEY。
mailto = ""
```

**质量下限**：分级是质量闸门的输出，随候选落库、**不丢数据**；"LLM 该不该看到"由这个阈值在读取端决定，`--min-grade A|B|C` 单次覆盖（[ADR-0044](../决策/ADR-0044.md)）。**初版只实现硬排除**（撤稿与黑名单），分级与 `--min-grade` 顺延（[ADR-0051](../决策/ADR-0051.md)）。

**摘要截断**：`search --abstract` 打开时每条摘要截断到 `abstract.chars` 个字符（默认 800）；`lookup` 不受它约束，固定带完整摘要。取值规则与「摘要可能不是逐字符原文」的边界见 [ADR-0058](../决策/ADR-0058.md)。

**余额降级**：`search` 与 `sync` 每次开始取数前、每个源返回后检查剩余额度；低于 `quota.min_remaining_usd` 就停止后续请求。成功或 HTTP 错误响应均读取额度头；尚未读到余额时不能预判耗尽。`degraded.reason` 按实际进度说明整次跳过或只完成部分来源，字段语义见 [IFACE-PAYLOAD §1](../接口/输出载荷.md)。`sync` 一次跑多条查询时共用一个客户端，所以前一条查询读到的余额会拦住后一条。

## 4. 命令

| 命令 | 作用 |
|---|---|
| `profile show` | 回显当前画像与查询清单 |
| `profile check` | 解析校验：语法、必填字段、**查询名重复**；失败报出错行 |
| `profile scaffold` | 吐出带注释的空白模板 |

**CLI 不写配置**：新建与修改由 agent 直接写文件，改完必须跑一次 `profile check`。

## 5. 未配置时的引导流程

1. `profile show` 报「无画像」→ agent 进入引导。
2. **先出草稿，不要发问卷**：从本地库已有的主题、当前对话里用户说过的话、必要时一次公开检索试探，拼出画像初稿。
3. 把初稿逐条摆给用户确认与增删：方向名、`all_of` / `any_of`、venue 白名单、回看窗口。
4. 写 `config/profile.toml` → `profile check` → 把解析结果回显给用户。

**用户随时可以要求修改**：agent 直接改文件并重跑 `profile check`，没有别的通道。

## 6. 备份与分享

> ⚠️ **代码与数据都在仓库里**（[ADR-0055](../决策/ADR-0055.md)）：重新 clone 或 `git clean -xdf` 会**丢掉 `config/`**，而 `profile.toml` 是全项目唯一不可重建的用户数据。改动前先备份。

- **备份**：复制整个 `config/` 即可。它不含密钥，可以进 dotfiles。
- **分享**：把 `profile.toml` 发给同学，他改回 `profile.toml` 放进自己的 `config/`。**工具不参与这件事**（[ADR-0040](../决策/ADR-0040.md)）。

## 7. 译名表

`config/terms.toml` 只在翻译时用得上：让不同会话、不同论文的中文译名一致（[ADR-0054](../决策/ADR-0054.md)）。

```toml
# config/terms.toml
# 文件缺失 = 空表；版本 = 文件内容的 sha256 前 8 位，改一次自动换版。

[[term]]
en = "world model"
zh = "世界模型"

[[term]]
en = "unmanned aerial vehicle"
zh = "无人机"
```

- **保持不译**：`zh` 写与 `en` 相同的值。
- **改动的代价**：改一个词会让相关译文缓存整批失效——这是正确行为（译名变了，旧译文就不该复用）。
- 与 [术语表](../术语表.md)（项目术语）无关，两者不同名不同物。
