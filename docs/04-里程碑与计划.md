# 里程碑与计划

> 里程碑、验收入口与下一步。设计见 [DESIGN](02-设计说明书.md)，未决事项见 [OPEN](06-待决事项.md)，操作手册见 [运维/](运维/README.md)。

## 1. 里程碑

| 阶段 | 内容 | 验收标准 | 预估 |
|---|---|---|---|
| **M0 额度与增量实测** | 见 [RUN-M0](运维/M0-额度与增量实测.md)：申请 OpenAlex 免费 key → 复测 `from_created_date` / `from_updated_date` 的付费层归属 → 确定增量实现路径。**它是 M1 的省钱前置、不是阻塞**：增量已有「`publication_date` 回看 N 天 + 本地去重」兜底（[DESIGN §4.7](02-设计说明书.md)） | 无 key 与有 key 各测一次，额度响应头与增量可行性有结论；结论写成一份实验记录并登记到[实验注册表](实验/README.md)，随后从 [OPEN](06-待决事项.md) 移除 Q1 / Q4 | 1 小时 |
| **M1 检索 + 去重 + 落池** | CLI 骨架（JSON 信封、退出码、`SCHEMA_VERSION`）、**两份新契约落地**（[IFACE-SOURCE](接口/数据源适配.md) 的逐源映射与 work 级聚合、[IFACE-PAYLOAD](接口/输出载荷.md) 的结果条目与错误码）、配置解析与 `profile show/check/scaffold`（四份配置见[配置目录](使用/配置.md)）、OpenAlex / arXiv 客户端（Crossref 只做 `lookup` 兜 DOI）、去重与落池（**内部步骤，不暴露命令**，[ADR-0047](决策/ADR-0047.md)）、候选池、纯规则硬排除（撤稿 / `paratext` / venue 黑名单）、run 收尾批量补桥、写锁与 `busy`、契约测试脚手架 + 脱敏 fixture | 关闭 REQ §5 的「零重复候选」「零重复写入」「撤稿 / 黑名单不返回」三条：同一查询重跑 0 重复候选，已入池论文被正确拦截、不重复计费；`profile check` 能报出错行；契约测试覆盖信封、退出码与 `SCHEMA_VERSION` | 4–5 天 |
| **M1.5 文本化流水线** | 便携 pandoc 接入；arXiv LaTeX 源码 / HTML → `paper.md`；图件落盘并在 Markdown 中相对引用；锚点注入。**技术路线已验证**（8 篇 eess.SY：`paper.md` + `figures/`、47 张图 0 失败、691 条交叉引用改写，见 [EX-2026-10-14-textify](实验/EX-2026-10-14-文本化.md)）；剩余是产品化：错误处理、增量、缓存、CLI 契约，以及 [EX-2026-10-14-textify §7](实验/EX-2026-10-14-文本化.md) 第 1–2 条（引用解析器补齐） | `textify` 端到端跑通：给定一篇，产出 `paper.md` 与 `figures/`（图件相对引用、锚点可定位）。**产物落 `bytes/`、投影 `works/`、登记 `artifact` 与「重复调用命中缓存」归 M2**（见本表 M2 行的「全文按需取用通道」） | 产品化 2–3 天 |

| **M4 脉络图谱**（初版之外，可选） | 引用边抓取、`work`/`citation_edge` 表、main path 查询、Mermaid 导出 | 给定种子论文产出可读的演进脉络图 | 3–5 天 |
| **M5 Zotero 桥接**（初版之后） | 见 [RUN-M5](运维/M5-Zotero桥接.md)：备份 → 升级 Zotero 10 → 授权 → 写读删；`promote`（provenance + 回滚）；child note 写回；`.zotero-ft-cache` 全文通道；`LibraryBackend` 三实现 | 一条真实条目能被写入、读到、删除且可按 `run_id` 一键撤销；升级后本地库无损 | 4–6 天 |

## 2. 下一步

1. 执行 [RUN-M0](运维/M0-额度与增量实测.md)：申请 OpenAlex 免费 key 并复测额度与增量口径，产出结论记录（落 `docs/实验/` 并登记注册表）。它是 M1 的**省钱前置，不是阻塞**。
2. **当前落地与缺口**：M1 全量（检索 / 去重 / 落池 / 候选池 / 信封与退出码 / `profile`）与 M1.5 的**取件-装配链**（e-print 解包、arXiv HTML 清洗、pandoc 调用与归一化、图渲染器降级、`converter_version`）已在 `src/academic_search/`，测试见 `tests/`；M1.5 仍缺 [EX-2026-10-14-textify §7](实验/EX-2026-10-14-文本化.md) 第 3–5、7 条（子图 id、单公式布局表、HTML 自定义宏、KaTeX 公式自检）。**`textify` 命令尚未接线**：它的契约整条挂在「产物落 `bytes/`、投影 `works/`、登记 `artifact`、命中缓存」上，这些属 M2，当前能力停在 `service.run_textify`（只写调用方给的目录）。
3. 真实的第一次检索前先落领域画像（`config/profile.toml`）：`profile scaffold` 出模板、`profile check` 校验（见[配置目录](使用/配置.md)）。正文检索方案已定：扫 `works/`（[ADR-0036](决策/ADR-0036.md)）。
4. M1 → M1.5 产品化 → M2 → M3 依次推进，**初版到此为止**（[ADR-0046](决策/ADR-0046.md)、[ADR-0051](决策/ADR-0051.md)）；`export`、A/B/C 质量分级、引用图谱（M4，可选）与 Zotero 桥接（M5）都在初版之外，各自的触发重估信号见 [ADR-0051](决策/ADR-0051.md)。
5. **调度不进工具**：频率由用户在自己的调度器里配（[ADR-0038](决策/ADR-0038.md)）；**专用翻译模型**是计划内后续（[ADR-0037](决策/ADR-0037.md)）。
