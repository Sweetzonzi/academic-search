## 2. 下一步

1. 执行 [RUN-M0](运维/M0-额度与增量实测.md)：申请 OpenAlex 免费 key 并复测额度与增量口径，产出结论记录。它是 M1 的唯一前置。
2. 文本化流水线（M1.5）技术路线**已验证**（[EX-2026-10-14-textify](实验/EX-2026-10-14-文本化.md)），可与 M0 并行推进产品化；动手前先处理 [EX-2026-10-14-textify §7 遗留清单](实验/EX-2026-10-14-文本化.md) 的第 1–2 条（引用解析器补齐）。
3. M1 开始前先确定领域画像（`Q10`）。正文检索方案已定：扫 `works/`（[ADR-0036](决策/ADR-0036.md)）。
4. M1 → M1.5 产品化 → M2 → M3 依次推进；M4 可选，M5（Zotero 桥接）放在初版稳定之后。
5. **调度不进工具**：频率由用户在自己的调度器里配（[ADR-0038](决策/ADR-0038.md)）；**专用翻译模型**是计划内后续（[ADR-0037](决策/ADR-0037.md)）。
