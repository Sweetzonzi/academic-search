# 实现约定

> **状态：框架，待设计。** 只列已知必须遵守的项。

## 1. 依赖

- 核心链路仅用标准库；重活（向量、PDF 版面、Zotero 客户端库）放独立虚拟环境按需启用。

## 2. 必须遵守的实现约束（破坏即伤及契约或身份稳定性）

- 禁止硬删 `record`，删除一律标 `tombstone`（[IFACE-DATA §4](../接口/数据模型.md)）；
- 表设计的语义以 [IFACE-DATA](../接口/数据模型.md) 为准，物理 DDL 写在 `src/**/schema.sql`——DDL 不得引入数据模型里没有的表或唯一键；
- `record_uid` 的派生规则进 `SCHEMA_VERSION`，改动即视为迁移；
- 面向用户的入口统一返回 `work`，不返回 `record`；
- **写事务用 `BEGIN IMMEDIATE` 并先取锁**：拿不到即 `busy` 退出，不排队（[ADR-0055](../决策/ADR-0055.md)）；
- **路径一律现场拼、不落库**：`read` 定位器返回的 `bytes/` 路径同样如此（[ADR-0053](../决策/ADR-0053.md)、[IFACE-STORE §2](../接口/存储与迁移.md)）。

## 3. 配置、日志与退出码

- **配置解析**：只用标准库 `tomllib`；只读 `config/profile.toml` / `sources.toml` / `search.toml` / `terms.toml` 四个固定文件名，目录里的其它文件一律忽略（[ADR-0040](../决策/ADR-0040.md)）。字段集与缺省值以[配置目录](../使用/配置.md)为准——那是唯一家；解析失败由 `profile check` 报出错行。
- **日志**：JSONL 结构化日志写 stderr，stdout 只放信封（[IFACE §1](../03-接口契约.md)）。
- **退出码**：0 成功 / 1 失败；需要区分的失败在信封 `error.code` 里细分（错误码表见 [IFACE-PAYLOAD §6](../接口/输出载荷.md)）。**参数解析失败不经信封**：argparse 直接退出，退出码 2、usage 写 stderr。
- **时区**：库里时刻一律 UTC（ISO-8601 带 `Z`），日期型字段存 `YYYY-MM-DD` 原值不换算；报告的日期渲染用本地时区并在头部标明（[ADR-0055](../决策/ADR-0055.md)）。

## 4. 模块职责与测试

**目录与职责**：`src/academic_search/` 一个包，入口 `__main__.py`；模块按职责切分，**一个事实一个家**（表设计的事实家是 [IFACE-DATA](../接口/数据模型.md)，字段语义的家是 [IFACE-SOURCE](../接口/数据源适配.md)）：

| 模块 | 职责 | 不许做 |
|---|---|---|
| `cli.py` | 参数解析、命令分派、信封组装与退出码 | 不碰 SQL 与网络 |
| `service.py` | 用例编排：检索 / 查询 / 入库 / 成本汇总 | 不解析参数、不组装信封 |
| `envelope.py` | 信封与载荷结构、`SCHEMA_VERSION`、错误码常量 | 不含业务判断 |
| `config.py` | 四份固定配置文件的解析与校验 | 不写配置、不联网 |
| `identity.py` | `record_uid` / `work_key` 派生、`normalize(source_id)`、`title_key` | 不改库 |
| `store.py` + `schema.sql` | 连接、`schema_version` 迁移、写锁（`BEGIN IMMEDIATE`）、全部 SQL | 不拼 `bytes/` / `works/` 路径 |
| `sources/`（`openalex.py` / `arxiv.py` / `crossref.py`） | 请求、分页、限流、逐源字段映射 | 不写库（返回记录对象） |
| `group.py` | L0/L1/L2 判据、合并与重定向、补桥 | 不联网（桥由 `sources/` 取） |
| `paths.py` | `bytes/` 与 `works/` 路径拼装、硬链接与只读、引用计数 GC | 不把路径交给 `store.py` 落库 |
| `textify.py` | 主 `.tex` 判定、e-print 解包、pandoc 调用、归一化、PDF 图渲染、锚点注入 | 不做摘要（那是 `digest`） |
| `htmlclean.py` | arXiv HTML 的正文抽取、LaTeXML 清洗、图件来源收集（`lxml` 可选，缺失即 HTML 路线不可用） | 不碰 LaTeX 路线；不改库 |
| `contenthash.py` | 源文本规范化与 `content_hash` | 不碰库 |
| `report.py` | `run.json` / `report.md` / `latest-report.md` / 日志 | 不决定跑什么 |

**测试怎么跑**：`pytest`（Anaconda 自带 7.4.4 即可）。`tests/` 与 `src/` 平级；**契约测试不联网**，网络层一律走 `tests/fixtures/` 里脱敏后的真实响应；live 测试用 `-m live` 标记并默认跳过。三个必须先有的套件：[IFACE-STORE §1](../接口/存储与迁移.md) 的身份派生向量、[IFACE-SOURCE §6](../接口/数据源适配.md) 的 V1–V3 三个哈希向量、信封与退出码的契约测试（分层见 [VERIFY §2](../05-验证与验收.md)）。

**外部工具的依赖与记录**（装了就用，不装就降级，**缺一不影响核心链路**）：

| 工具 | 用途 | 缺失时的行为 |
|---|---|---|
| 便携 pandoc（`vendor/pandoc/`） | LaTeX / HTML → Markdown；定位顺序 `ACADEMIC_SEARCH_PANDOC` → `vendor/pandoc/` → `PATH` | `textify` 报 `source_error`，不产出 |
| `pdftocairo`（TeX Live）或 PyMuPDF | PDF 图 → PNG | 依次降级，最后保留 PDF 链接并在产物里标注 |
| `lxml` | HTML 正文抽取 | `--source html` 不可用，LaTeX 路线不受影响 |
